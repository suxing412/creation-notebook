## 1. 路线检查（验收 1）

工具：`measure_loop.py` 里的网格 BFS 段，制作时改成读装配包的输出。参数：
- 网格 0.1 m，4 连通；
- 身体半宽 0.3 m（方形腐蚀）；
- 头顶净空 1.9 m。测射线**从门基以下 0.1 m 起算**，这样埋进地面的门叶和门墩也会被当成障碍；
- 支持面取门基上下 -0.05…+0.10 m；
- 外点 (0,-25)，内点 (-0.4,11)。

| 编号 | 检查 | 预期 |
|---|---|---|
| P1 | 外到内，只许走西侧门道（\|y\|≤5 时 x≤-5.8） | true |
| P2 | 内到外，只许走东侧门道 | true |
| P3 | P1 和 P2 都成立，即回路闭合；三档门体与三档地面的 3×3 组合都要跑 | 9 组全部 true |
| N1 | 只许走中央（\|y\|≤5 时 \|x\|≤3） | false。如果为 true，说明中门没有阻断，或者检测器失效（准备期就出过这个错：射线从门基以上起算，漏掉了埋入的门叶） |
| N2 | 去掉旧路，从西连接片到东连接片 | false |

| N5 | 错误注入：把门体沿局部 x 平移 +0.5 m 再跑 P1 | 应当失败，或在报告里标出路线变化 |

额外要求：
- 支持面沿路线逐格的高差不能超过 0.05 m，超过的每一处都要列出来。
- 连接片与旧路之间的缝不能超过 0.015 m；准备期实测 0.010 m。
- 不能用中心射线代替上面的网格检查。网格结论也只写成「离散局部通行」。

## 2. 侵入分类（验收 2）

每一对接触都要归入下列一类，不能把整对物件一起豁免：
- **合法局部接面**：两翼外面与墙帽，残差 ≤ 0.001 m；准备期实测 0.000122 m。两翼内面与门墩外缘的矩形 x=±12.8, y∈[-5,5], z∈[0,5]。连接片与旧路之间 0.01 m 的缝。
- **正体积侵入**：给出面积×深度和位置，再由协调者签字决定是「接受嵌入」还是「切孔」。准备期基线：
  - 旧路进西墩 2.121 m²×0.04 m，约 0.085 m³；
  - 旧路压在中央门叶底下 1.051 m²，约 0.042 m³；
  - 旧路进中央门框 W 0.064 m²、E 0.0128 m²。
  - 容差：制作后重测，面积变化超过 ±0.01 m² 就要解释原因。
- **完全包含**：用射线奇偶判断「点在实体内」，但必须对每个闭合壳**分别**建 BVH。准备期发现，门体合并网格里门头顶面与楼板底面在 z=5.0 重合，合并后做奇偶测试会出假阳性。
- 负例：
  - 人为把地面板抬高 0.2 m，侵入面积必须变大并报 FAIL；
  - 把两翼外移 0.01 m，墙帽残差必须超出容差并报 FAIL。
- 侧门地面与开启门叶、条板的最小水平间距 ≥ 0.5 m；准备期实测 0.82 m。
- 地面顶点在门实体内的数量必须是 0；准备期三档都是 0。

## 3. 旧位置不漂移（验收 3）

- 装配后，每个原节点的世界矩阵与 T 的最大差 ≤ 1e-4；准备期分块实测 1.85e-5。墙、旧路、条件路的矩阵和顶点逐值比较，差值 ≤ 1e-6，并且三角形数量不变。
- 门体三档的 vertex/index/UV/材质字节，与 §0 的源 GLB 相同。两翼要么是新增的独立 primitive，要么写明「并入 earth」，并给出前后 SHA。
- 安装再撤回：把装配包加到选定的基线（docs bce3211 或母版 1e8c4d，由 LY-010 定），再撤回。撤回后所有原节点的 SHA 和矩阵都要与安装前一致；新节点清单与 `remove_on_rollback` 完全一致。旧方案（库卡附件）和新方案（LY-016 地面）不能同时载入：同时载入时，覆盖重叠面积必须是 0，否则 FAIL。

## 4. 三档与公共底线

- 每个 GLB 不超过 15,000,000 字节。LOD 之间不能是复制改名：三档的三角形数必须互不相同，也要与源 GLB 对得上（门 10100/1708/548，地面 4032/1152/72）。
- 回读必须通过 glTF2 校验：UV0 存在，没有 NaN，没有退化三角形，纹理内嵌。准备期 audit.json 已对源件显示全部合格。
- 预览：同一机位的前后对比、反面、穿过中央门道的剖面，都用 CPU 渲染并标注「CPU」。不声称做过 GPU 或浏览器测试。
