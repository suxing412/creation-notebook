## 2. 必跑检查与通过条件

### T1 互不侵占（验收 1）
`check_staging.py` 对每个用例做两类判断：
- 域（OP、ST）和每个占位盒的足迹，与每个禁入区做矩形相交（重叠 > 1e-6 m 即失败）；
- 占位盒与现有三角形做 BVH 面相交（只做表面，不能称实体穷尽），并单独列出与路带的相交。

通过条件：
- 正例的 `keepoutHits` 为空，`intersectObst` 和 `intersectRoute` 也为空；
- 与 route_public 的最近间距 ≥ 3.0 m（测量值），与井域的最近间距 ≥ 30 m（测量值约 37.98 m）。

允许的接触只有一种：**共边**，即 ST 与 route_east 共用 x = 24.0，OP/ST 与 LY-022 共用 y = 5.0。共边必须写成端口，不能写成重叠豁免。

### T2 空载 / 占位两态（验收 2）
- **空载**：OP 和 ST 全域每 0.1 m 采一点，1.8 m 体高以下被占为 0；
- **占位**：放入 LY-027 冻结的占位。现在用的是 4 个 C 测试盒 P1–P4，各 0.8×0.7×0.9。逐个检查：
  - 完全落在 ST 内；
  - 3×3 底面间隙，|gap| ≤ 0.005 m；
  - 与现有三角形不交；
  - OP 带在占位状态下仍然 0 被占。也就是说，占位不能挤掉人站的那条带。
- **两态互斥**：同一个暂存位不能同时出现在空载和占位两套里；每个占位都有可删除的 ID。
- **撤回**：删掉全部占位后，重新跑空载用例，结果必须和安装前逐字段一致（samples、miss、blocked）。

### T3 真实三角支持（验收 3）
在 OP+ST 全域向下打射线，只打地坪对象。通过条件：
- 未命中为 0；
- 朝上面不超过 1 层（`doubleLayer = 0`）；
- |z − 0.200| ≤ 0.005；
- 法线 z ≥ 0.99；
- 列出命中的三角形，prep 实测是 `C_market_ground_well_A` 的 1 个三角形；
- 和 route_east 之间的高差 ≤ 0.010 m（实测 0.010），和棚下地面高差为 0。

如果以后另做垫面：
- 垫面必须以**替换片**交付，由地坪负责人切出，不能叠在原地坪上；
- 用同一检查器复跑，双层必须为 0；
- 原地坪除切片以外，指纹不变（按 LY-022 的 `frozen-baseline.json` 方法：世界顶点按 1e-4 取整后求 sha256）。

### T4 棚下接口
- 接口线是 C02 屋面东缘 x = 21.3，y 5.12–6.88（两根角柱之间 1.76 m）；
- OP 带头顶在屋面以外，到桌边 0.175 m，可以伸手；
- 要记录：桌面高 1.09–1.21，棚下净高 2.376；接口棚的柱头间隙还没修（LY-023 缺口 B）。LY-023 交付后要复跑，验证本项没有挡住它的垫件；
- 不宣称棚下可以站人：屋面超出桌边只有 0.175–0.275 m，小于 0.6 m。

### T5 回退与不变量
- 安装前后对比分块全部节点的指纹（同 LY-022 方法）：除本项新增节点外，变化为 0；
- 城内组 A 的 market-cluster 和 N2 SHA 不变；
- 撤回后，场景节点集合与安装前完全相同。

### T6 三档
- LOD0 在分块上跑全套；
- LOD1/LOD2 用库件加偏移 (214.286, 0.20, −1959.184)，再加上分块的地坪跑全套。四棚坐标与 LOD0 不一致就失败；
- LOD2 的桌子和支架是合并的，只检域和支承，不检桌边接口。

## 6. 基线变更时
1. 先跑 `scripts/verify_inputs.py`；
2. 若 SHA 变了，重跑 `survey_islands.py`，先确认四棚和井的坐标，再更新 spec；
3. 不许直接复用 prep 里的数字。
