## A. 旧失败接缝对应到具体几何

**A1 基线复现（负例，必须失败）**
- 做法：对 lib1 和 lib2 跑 `measure_seam.py`。
- 预期：
  - lib×wA11、lib×wA00：629 个采样格的间隙在 5.000 ± 0.001 m 之间，没有贴合的格子，墙端外露 1.438 m²。
  - lib×wB：975 格，间隙 5.000 m。
- 判定：数字与上面不一致，说明输入漂移，停止。

**A2 失败几何定位**
- 报告里写明两处空缝：
  - x ∈ [−16, −11] 和 [11, 16]（局部坐标）；
  - 截面按 3.1 节的 A 墙梯形（底 ±3.995 @ z 0.17，顶 ±2.80 @ z 6.20）；
  - 每侧空缺体积约 205 m³（A 墙）。
- 端面引用：门的端面是 gate-B-static_earth 在 x = ±11 的面，墙的端面是 C_wall_A_11 和 C_wall_A_00 的端盖。

**A3 修订后正例**
- 做法：把 lib 和新增件一起作为门侧网格，再跑接缝采样。
- 预期：
  - 对 A 墙：所有两边都打中的格子满足 |gap| ≤ 1 mm；墙端外露 ≤ 0.0625 m²（不超过 1 格）；不允许出现 gap < −1 mm 的格子。
  - 体积交集（EXACT 布尔）≤ 0.001 m³。
- 参照：母版城内版本的成绩是 652 格、0 外露、0.0004 m³。

**A4 截面吻合**
- 预期：在 x = ±15.9 处，新增件截面的 y 范围与墙截面相差 ≤ 0.05 m，从 z 0.3 到 6.15 逐 z 检查（母版城内版本是 ≤ 0.03 m）。
- 翼顶在 |x| = 16 处的高度 = 墙顶 ± 0.005 m。

**A5 B 样本**
- 如果 LY-010 要求服务 B 样本，B 组互斥件对 wB 也要满足 A3 的标准。
- 如果只服务 A 样本，必须**保留负例**：A 组件 × wB 仍有约 22 m² 空缝；报告写「只服务 A 样本」，B 样本被选中时不加载 A 组件。

## B. 三档独立检查地面和墙端，不重复旧门体

**B1** LOD0、LOD1、LOD2 三档各自独立跑 A3、A4 和 B2–B4，不能拿某一档的结果顶替另一档。缺 LOD0 就把近景一档标为「阻断：缺 lib0」，不写通过。

**B2 地面与底部支承**
- 新增 pad 的顶面高度，与 LY-005 冻结的门位地面端口相符，容差 ≤ 1 mm。
- 门底（z0 + 装配平移）与 pad 顶面的残差 ≤ 1 mm；墙底 0.17 与 pad 顶面的残差 ≤ 1 mm。
- 门台底面在支承面上的投影覆盖率要 100%。参照：lib 的底面面积 72.0 m²，按 0.25 m 网格向下打射线，必须全部打中支承面。
- 负例：去掉 pad，覆盖率必须降到 0%（城市里这一带没有任何地面）。

**B3 门道地坪**
- 三条门道（x ∈ [−9, −5]、[−3, 3]、[5, 9]）里，按 0.25 m 网格从 z = 3 向下打射线，必须全部打中 pad 顶面。
- 门道净空 = 木构底面 − pad 顶面 = 5.20 ± 0.005 m。
- pad 的边缘（y = ±10 或冻结值）如果有台阶，要列出高度，并写明是否交给道路和地面席位处理；不能把台阶算作「已通行」。

**B4 不重复旧门体**
- 新增件与 gate-B-static_earth 的体积交集 ≤ 0.001 m³。
- 新增件里不能有任何顶点落在门台包围盒（x ±11 × y ±4.5 × z 0–10.45）的内部（容差 1 mm）。
- 交付里不能出现被改写的门台、木构、瓦面网格。
- 负例：如果把母版的 city_B_earth 当作新增件交上来，必须被判为失败（它与 lib 门台交集很大，墩子重复）。

**B5 档间关系**
- 三档之间的轮廓差异要写清楚。
- 不能把 LOD0 复制改名成另外两档：检查三档 vhash 是否不同。如果低面数件本来就相同（新增件只有几十个三角面），要在报告里如实写「三档同几何」及原因，并交 LY-007 判定。

## C. 移除新增件后恢复原状态

**C1** 安装：输入 lib + wA，加新增件，节点数 +3（seam-W、seam-E、pad），装配平移只作用在门的根节点上。

**C2** 撤回：删掉三个新增节点、撤销装配平移，然后检查：
- gate-B-static_earth、timber、tile 的顶点 vhash 与基线相同（12f982f3e8526921、ecd2fdbf86888beb，瓦面另算）；
- 世界矩阵与基线相同；
- 材质名集合不变。

**C3** 撤回以后重跑 A1，结果必须回到 5.000 m 空缝（证明撤回真的生效）。

**C4** 墙段 wA00 和 wA11 在安装前、安装后、撤回后，SHA 都不变；它们本来就是只读的。

**C5** 互斥：新旧门体不能同时加载。如果将来有母版城内版本的 xia-B 分块，与本包互斥，不能叠加。

## D. 公共底线

**D1** 单个 GLB ≤ 15,000,000 B。纹理内嵌，有 UV，没有 NaN 或无限值，没有退化三角面。用 LY-008 的检查器跑；同时要能跑出负例。

**D2** 新增件焊接后必须是闭合流形：边界边 = 0，连着 2 个以上面的边 = 0。墙端贴合面按合法的局部接面归类，不能整对豁免。

**D3** 材质用 LY-007 冻结的 LY_P01_earth 语义。

**D4** 预览：同一机位拍安装前、安装后、反面、x = ±13.5 和 y = 0 两处剖面，标明是 CPU 渲染图，用统一的 render.py。

**D5** 官方 `lab/tools/build_assets.py --check` 只在 LY-100 合并队列里跑，本席位不跑。
