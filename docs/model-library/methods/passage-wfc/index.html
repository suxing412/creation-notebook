结论与边界

WFC确实传播相邻端口限制，直/弯/T/端头改变真实通路；但局部规则无法排除孤立分量。下一步应评估全局路径约束或有界回溯，而不是锁死所有路。

4米格、1.6米口、0.2米地坪、2.2米预留净高均为试验参数。独立几何检查针对盒体与正交变换；相邻地坪仍有内部接触端面，未合并消除。无GPU/手机/引擎验收。

前三例度分布或环路数不同，证明至少三类非同构图，不仅旋转/镜像。样本通过率3/20不代表全部seed。
