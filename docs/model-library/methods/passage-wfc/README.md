# 通行接口试件：独立WFC组合研究
2026-11-03，passage-wfc-0.1。独立方法试验，不替换早期院落v01/v02，不接洛阳，不计三件新作品。

## 先模型库、后组合
四个真实GLB为一个研究组：直、弯、T、端头。登记为第6个研究资产组；此批发布实访待核验，原5组已有公开记录。原点、尺寸、socket与SHA见相邻 luoyang-passage-interface-modules/contract.json。模块并非汉代廊房或住宅品质。先核每GLB SHA，再实例化；没有用平面牌子充当3D模型。

## 全量结果
固定seed0–19，3×3格，固定南入口、北出口与外边界，不锁任何内部通路。四类14种朝向状态，同权重、最低域大小（同权重等价最低熵）选点、邻接传播，无回溯/重启，30000次邻域修订上限。
20/20满足局部socket配对；独立全局验证有17个断连，仅7、15、18三个通过。完整失败结果保留results.json，不能把三个展示例包装为高成功率。
- seed7：9条内部边，环路秩1，度数分布1:1/2:7/3:1。
- seed15：8条内部边，环路秩0，度数分布1:2/2:7。
- seed18：8条内部边，环路秩0，度数分布1:3/2:5/3:1。
这些图不变量不同，证明至少三类非同构连通拓扑，不仅是旋转、镜像或换色。

## 真正约束与负例
每个P口必须邻接对向P，X必须邻接X。端口宽1.6、地坪高.2、预留净高2.2与世界锚点/方向都属于接口；这些数字纯C设计参数，不是历史制度。
强制中心N端头、右侧W端头：两锁定状态各自都在初始域内，但共享边一开一闭导致传播矛盾，不是边界预先排除。另测0.1标高差、预算中止、手改布局断路或接口错误、固定20seed确定性、全部实际传播裁剪和全局失败可检出，共8项通过。
宽度/标高/净高接口比较函数已写，但当前求解状态共用同一尺寸，求解器只传播类型/方向；不能声称已在混合尺寸库中完成数值约束搜索。

## 真实几何
三例用四原GLB正交旋转/平移装配，保存每tile assetSHA、位姿、组合GLB和CPU图。所有原模块近景字节保持原样，未简化以凑数量。
导入原几何后的世界轴对齐盒体AABB未见正重叠；组合GLB再次独立导入，也检查焊接1e-6后的几何非流形、退化、正体积及正重叠。此法仅适用于本次盒体与90度旋转，不能推广到任意曲面。并非完整有向三角逐点相等认证。
地坪拼接处保留内部接触端面。相邻挡板为两层内缩板，不是共用古建墙；不应称最终建筑。没有动态/角色碰撞或跳跃测试，窄角缝不作试验通行口。CPU渲染都已目视查看；不是GPU、手机、实时闪烁或Godot/Unity验收。

## 首稿后检索与评审
2026-11-03再读Boris《Wave Function Collapse tips and tricks》：https://www.boristhebrave.com/2020/02/08/wave-function-collapse-tips-and-tricks/ 。作者明确区分局部组合和全局路径约束，并举固定入口出口与路径连接的做法。
本试验的17/20失败说明下一步应引入独立全局路径约束或有界回溯，不能用锁死内部路网“修复”。本轮保留这个失败率，不为好看重跑挑种子。参考没有变成汉代依据。原始机制：https://github.com/mxgmn/WaveFunctionCollapse 。未复制作者代码或图片。

## 路线选择
完整住宅方案应先做多尺寸占地、原点、外巷/屋檐与门锚点。已有18×24与28×36院落且原点不同，socket尚null，不能直接塞同一格。若地块道路全固定只挑院型，多数属于条件随机选择。
构件路线适合真实相邻接口限制，但需要独立制作可审构件；这次四个试件仅证明此路线可实施。历史形制与复杂屋面仍须参数生成/构造规则，不由WFC创造。

## 复现
解压后保留两个同级目录。Python标准库即可运行 `python3 luoyang-passage-wfc-study/solve.py` 和 `make_demo.py`。Blender4.3.2运行 `render.py` 读取同级模块目录，输出实际装配与CPU图；`audit_combined.py`检查导出。渲染依赖CPU Cycles，不开GPU。
固定当前配置、排序、Python版本与种子；换参数需重新测试。index.html无外部JS依赖；无脚本仍可看三例、全结果及下载链接。HTML静态/JS语法检查不冒称浏览器键盘和手机实测。
