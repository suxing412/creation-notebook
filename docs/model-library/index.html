复用与生成

现在可用：真实GLB、原始生成脚本、固定几何预设、有限验证契约。变体、姿态、LOD与版本分别记录。

轻量后续方案：固定视觉语言和接口，再在经测试的变量内做少量变化。井的seed目前仅是元数据，尚未驱动随机生成；A/B两点不能当作已测连续区间。

WFC的范围：用于有邻接约束的模块组合，不是把任意整院随机拼成城。已有通行试件实验，住宅和井不称为WFC生成。

配方应保留什么？

固定项、可变项、已测预设、失败边界、解析后完整参数、版本与SHA、检查器身份。未测范围保持未知，不提供无功能的随机按钮。
