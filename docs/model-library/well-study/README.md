# 井栏与井架：独立模型库候选

## 范围与证据
A四坡亭＋井字木栏、B两坡亭＋圆折沿，都是馆文关联类型组成的C设计，不是同一件文物逐构件复制，也不是东汉洛阳180年的实址复原。馆文原始链接和逐条限制见inputs/reference-contract.json；图片本轮未实际读取成功，不能声称视觉复原。灵宝张湾2号与3号的细节不能混为一个对象；刘家渠类型概括也不能当确定组合。烧沟西汉晚井架后配事实保留。

## 资产规格
Blender4.3.2、米制、井口中心地面z=0、原生Z向上，GLB Y向上。没有placement。A近景9644tri/低LOD3216tri；B近景9228tri/低LOD2784tri。四GLB独立内嵌纹理，不需共享外部目录即可读取。9张自制PBR源来自已有土墙0.20/木/瓦研究，SHA绑定；不是古代真实色彩证据。纹理内存理论预算见qa/texture-budget.json，不是GPU测量。原生文件默认A近景可见，其他版本保留隐藏且按名分组。

## 复用契约
同一生成器改变口沿结构、屋面拓扑和跨度，非只换色。只测试A/B各两LOD，不保证任意连续参数。井口半径须大于0.386m、檐高大于2.2m、顶高大于0.2m、短井壁显示深度正数；这些是本机构的有限失败防护，不是汉代尺度。
演示环形地坪是可去除独立节点。井壁在地面下仅0.65/0.70m截断，未给井深/水位或水面。未来城市必须另做真实地面开口和周边流线验收，不能直接把井盖在完整地形顶面上；不推每院一井或公共井数量。

## 实际检查与限制
- 原生/实际GLB逐物件闭合、无退化，5位小数有向三角集合一致；5条井口射线实际通过，无假地板堵口。
- 两侧柱—横梁—抬脊立件—脊撑实际边界接点高差0。
- 容器对栏/井壁与轮对侧托的选定实际布尔交体0；绳槽约2.1e-14立方米数值残留，不称绝对0。
- 轴进入侧托约0.000147立方米/侧，是明确局部支承嵌接，不是整对豁免。轮轴孔摩擦、承载、绳动力学未验。
- 10个容器竖向行程包络只是静态设计净空，不是动画或人体通行实测。四失败输入均被拒绝。
- 屋面有简化平瓦面和凸瓦列，脊与泛水仍简化；各固体拼缝、轮绳接点GPU动态闪烁未验。不是全构件间穿插归零结论。
- CPU图是真实生成几何，不等于Three/GPU、iPhone或最终设计验收。HTML支持按需加载、静态图及下载；本轮JS语法和静态资源检查，尚未浏览器交互验收。
