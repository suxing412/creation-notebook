# 无名宫门准入—庭地—殿前连接：制作依据

核查日期：2026-11-05。目标时代约公元180年。此为独立、未定位的C级空间兼容候选，不是某座实名宫门至德阳殿的复原图；宫名、门名和城市绝对坐标均为空。本说明不代表模型已经制作或路线已经通过检查。

## 可直接支持的功能

已直接复读[《后汉书·志第二十五·百官二》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/houhanshu/hhs124.html)：

- “卫尉”条记宫门卫士与宫中巡行；“南宫卫士令”“北宫卫士令”分别列职。可据此区分入口值守与内侧巡行，不得倒推特定房数、营房面积或巡行路线。
- “公车司马令”条注述诸门部夹道屯列、拦阻妄出入。支持通行两侧部署的功能关系，不证明两座独立门房，更不是某条道路的测绘记录。
- “宫掖门”条记居宫者口籍、符信核验与外人因事入宫的凭传。支持受控准入。“案省符”不能作为查验桌实物证据；站立工作台、门叶和候检区均为现代C级功能设计。
- “光禄勋”“五官中郎将”条另记宫殿门户、诸殿门的宿卫；“虎贲中郎将”条提到朝会在殿中。支持殿门具有独立值守语境，不支持“过宫门便可无条件进殿”。准入接口与殿前终点应在语义上分开。

这些记载支持功能节点的存在，**不记载本候选“核验通口→开放庭地→正面殿阶”的连续空间序列**。将节点接成这一条路，是本次C级工程方案，不是从文本还原出的布局。

## 本次新增应是什么

已有内容包括：德阳v2的殿阶与开放厅区、玉堂的殿庭、侧廊庑局部组合、无名宫门值守核验切片。现状摘要和实际检查记录已复读：palace-spatial-current-context-v1、palace-spatial-context-private-v1/inspect.log、palace-entry-function-evidence-v1；后者曾建议的核验切片目前已经存在，不再作为新需求重复申报。

真正可新增的是一份可拆卸的局部空间组合及实体连接地面：把既有核验切片内侧出口与一段庭地、殿前接近区接通，保留旁侧巡行/工作出口，明确外侧起点、门限、内侧分流点、殿阶前端点。若另接侧廊，单列分支并检查其真实阶梯入口，不以镜像对称或中心线代替入口。

- 可以复用德阳库中的C形体作“殿堂原型”，但组合的历史目的地须记为未指定；保留来源文件身份，不能将该来源名当成此路线通往历史德阳殿的证据。
- 庭地长宽、门殿间距、同轴或错轴、转弯、台阶高差、侧廊角度、铺面、朝向、门洞数、两值守单元数量和所有坐标均为C。既有A/B方案标签不是史料等级。
- 本次没有证据决定所属南宫或北宫，也不应凭旧B包络或新墙线把它放入城内。图示局部南北只是资产坐标，不是实址方位。
- 只计一项新增连接组合；复用的殿、值守单元、庭地和三LOD不能再次计作数项新建筑。不能仅增加参考空物体或路线线条就称为空间资产。

## 不能从考古材料补出的关系

[钱国祥《汉魏洛阳故城居中宫城制度考》](https://www.nopss.gov.cn/n1/2018/0704/c373410-30125781.html)明确把阊阖门及其北面连续两道门的始建时代归于曹魏，北魏沿用。本文的七间、三门道、子母阙、三道门与太极殿中轴，不得转作东汉180年的本候选形式或尺度。该研究可用于排除时代误用，不是本候选的平面模板。

[《人民日报》2026-03-25第11版，刘涛介绍2025年东掖门发掘](https://paper.people.com.cn/rmrb/pc/content/202603/25/content_30147047.html)说明此处东掖门始建魏晋，并排除同位置东汉宫门。其三门道殿堂式门与双阙不能为东汉宫门定点或定形。报道并未证明东汉不存在准入至宫内庭地的通行，只是不能借此址补全本方案。

## 交付时必须保留的边界

1. 单独文件/集合，可撤除，不改母版、旧库、既有隐藏状态或城内坐标。来源名可以记录在依赖表中；主标题、图例、对象历史名称不写“德阳宫门至前殿复原”。
2. 新支承面必须进入实际输出资产，而非只存在检查场景。门限、地面接缝、首阶、平台和转弯都检查有宽度与高度的通行体及足下支承；不要用中心线通过宣告连通。
3. 保留原核验切片开放边界的限制：它只控制中央通口，不构成完整宫墙、无绕行门禁或整宫安防。不要因接上庭地就把这一限制消掉。
4. 门扇开闭扫掠与内侧路径应复检；已有单件有限QA不自动覆盖平移、旋转、接地或新增连接后的组合。
5. 成果可称“C级无名宫门—庭地—殿前功能连接试案”。不得称实测平面、完整朝会礼仪路线、历史身份复原、人体步态或结构安全认证。

结论：有依据继续做一个实际、可逆、未定位的空间连接资产；没有依据将该组合指定为某个实名宫门与德阳殿的历史关系。新增价值是端口与支承连续的几何验证，不是提高历史确定性。
