# 雍门内侧接街与分层显示

本目录属于雍门配套附件，不作为独立建模作品。四个接街/接收文件和组合图统一收在雍门卡（m-luoyang-yong-gate），运行路径与城景装配不变；原件及源包仍归属r2026.11.05-6。

新增接街长49.616米、宽3米，沿既有模型接口平缓衔接40毫米高差；三档均为同一12三角实体，厚0.2米。几何和材质均属C级工程设计，非东汉御道测绘复原。连续支承与净空仅核到现有接收道路内3米，不代表完整城市交通、结构或排水验收。

全城冷开使用现成雍门门体/地坪LOD2及接街LOD2。雍门章按需加载原完整近档并替换远档，不叠加；不是随镜头距离自动切档。已有近看操作仍可用nearPath。

接收件是从既有主路无损提取的209三角完整连通分量，范围约1.4×1.8千米，不是50米短片，不另计新路。保留其内部平移，城市实例为恒等变换。原network文件、三个节点整体加载合同和excludeNodes完全不改；打开完整道路章后，原network替换接收片，不同时显示。
