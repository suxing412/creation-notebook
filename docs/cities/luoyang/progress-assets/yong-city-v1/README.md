# 雍门接墙与通口入城

本批保留原雍门完整近景，复用旧两翼接墙几何及逐角UV，新增连续局部地坪，接入现有西墙关系处。具体形制、坐标和地面仍为C设计，非考古测绘复原。

本目录实际提供三档 yong-apron-LOD*.glb、source.json、context.webp、entry.webp。GLB仅含两翼和汇流地面，不含门体；source.json引用已有公开近档门体，城市清单用同一确定矩阵组合，不重复上传门体。原生工程及生成器另存，不在仓库或网页中。

新地坪连接三孔门道的两侧汇流空间，并覆盖四墩与两翼底部；三档各68三角，采用512/256/无贴图。旧三条门下测试带仍保留为对照，与新地坪不能叠载。支承是几何覆盖，不是承重或历史铺地证明。

当前近档默认进入全城集合，首批模型响应体从1,913,020B增至3,872,084B；项目开场镜头仍指向旧住宅，不自动飞向新门。通过全城或雍门章节查看。缩放不切LOD。

两幅图是保存模型的CPU PBR实渲，不是网页截图。外部道路仍有约50米缺口，上层登临尚缺，不称全城交通或完整运营城门完成。

原64节点、44院、城垣和太仓原件不动。回退可移除本批两节点并恢复清单及卡片后刷新。发布记录以项目手记及批次标记为准。
