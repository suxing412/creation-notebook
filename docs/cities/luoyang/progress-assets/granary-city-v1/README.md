# 既有仓储组原位三档

三个GLB是同一组的互斥档位，不新增仓址或建筑数量。每档均包含原地坪，采用原城市绝对坐标；city-data的position保持[0,0,0]，不要再次平移。完整近档用于当前城景，中远档是独立备选，未启用距离自动切换。

文件：granary-city-LOD0/1/2.glb，cover.webp，LOD0/1/2.webp，source.json。本目录没有原生工程或重建源码；它们另行保存，不随网站发布。WebP是最终GLB导入后的CPU实渲，不是浏览器截图。

保留原位、原地坪和近档几何，最大继承顶点编码差12.16微米。入口仅在有限0.9米阶梯条带通过，1.8米压力条带失败保留；不证明连续人体、车辆或承重。东北对外道路仍未接通。区域文献和汉代明器仅作功能类比，形态、尺寸、两仓配置与旧示意点落位仍是C设计，不是太仓考古复原。
