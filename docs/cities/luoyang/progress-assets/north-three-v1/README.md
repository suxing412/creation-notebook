# 住宅试验区北缘三院

本次只把已交付的三屋对置、紧凑作业、足碓院各放入一处C级设计地块。原44院的矩阵、几何、材质和原型引用不变，总数为47院；不把远近档、棚或支承地面另计作品。三处工程坐标为(586,1234)、(612,1234)、(638,1234)，各18×24米；这是既有住宅试验区的北缘，不是东汉洛阳全城北缘，也不证明古代院址、院数或道路位置。

复用现有资产库GLB URL，未新增、重导出或复制任何模型文件。默认显示各自LOD2，进入“住宅北缘三院”章时一次加载三份原LOD0并替换远档，失败保留先前场景。回到全城不卸载已加载近档；重新打开场景才从远档开始，没有自动距离LOD。原有住宅章自动打开时仍只用远档。

唯一既有ground-retained节点改为默认显示，完整保留原629740字节、三个材质图元、21192三角和原矩阵。它覆盖约300×550米的原有地面，不是只加三小块。network仍不初始加载，原terrain章节的四文件组合不变；network内部三个节点的原子合同不变。没有新增路面或裁切地面。

## 实际空间检查

三块地面及屋檐南伸0.15米后的包络由当前retained真实顶面连续覆盖。三院与既有建筑最近水平距离约29.04、8.61、7.99米，院前70×3.75米公共条带接至现有3.5米宽道路。LOD0和LOD2实际模型中，三处入口分别在X581.2、607.2、633.2；指定0.8×0.8×1.8米长方体沿每院门内、院前条带、路内的三段连续扫掠，共18段无碰撞并完整支承。这只是指定路线及静态体积测试，不是全城导航、车辆、动态足碓、结构或消防认证。第二院屋檐包络距道路端的0.10米不是门洞宽度；路径从西侧入口侧向接路，不穿这条窄缝。

## 加载与界限

候选冻结前，对27个默认GLB的既有线上URL实测响应体合计1408005字节；这是旧部署上的测量，不是本批上线后的验收值。本地原件合计2948644字节，两种计量不能混用。本批新增城景引用会按既有发布规则保护原件，因此须在官方组站后复核预算，并在部署后重新核全部默认GLB响应体不超过C15的1900000字节。实际Three/GLTFLoader加载、失败/重试、重复、顺序与竞态在CPU环境验证；另读取线上实际压缩GLB进行默认加载验证。这不是浏览器冷开抓包、像素、真机或GPU验收。

三种院落继续使用此前冻结的住屋版本，未因此升级到013近景标准；既有内部闭合接面、固定门扇及生活细节不足仍在。近档引用原文件里的嵌入贴图，未新增重复副本，也没有声称解决C16。北宫新墙和古水系未配准的限制保留；与另待部署的13院区域分离，不改变其内容或加载方案。
