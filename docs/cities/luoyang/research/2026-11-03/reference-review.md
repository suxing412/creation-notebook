# 南组14院地表连接：首版后参考检索与采用边界

检索日期：2026-11-03 UTC。只记录原始链接与必要短摘要；未下载、转载外部图片或模型。此文是参考方法复核，不是已经看过本研究最终渲染的视觉验收。

## 1. 河南博物院：彩绘陶院落（含比较研究）
原始来源：https://www.chnmus.net/sitesources/hnsbwy/page_pc/dzjp/mzyp/chtyl/list1.html

**实际读取**：馆方比较研究分别列出郑州乾元北街西汉灰陶院落的门槛、台阶式踏道，以及洛阳张茅东汉绿釉陶院落的侧开门、围墙、大小不同建筑。于庄彩绘院落的年代存在西汉前期/东汉两说，正文明确承认争议。

**采用**：继续把入口视为地面—门槛—院内的过渡，不为碰撞清零删台阶；保留不同院落门位置和空间组织差异。作为形态比较，不能据此确定新街区位置。

**不采用**：于庄的豪华高楼、壁画、田园井渠不能推广成180年洛阳普通住宅；明器的厘米尺寸不可直接转换成城内道路宽度或真实踏步尺寸。本站6m/3.5m道路、门前渐变范围、地面材质色差仍为C设计参数。

证据类别：馆藏明器与博物馆比较研究，不是南组街区发掘。

## 2. Adam Sharp：Stylized Medieval Village（作者本人作品页）
原始来源：https://nads.artstation.com/projects/qJe9bL

**实际读取**：作者说明以模块工具包构建环境，使用材质高度信息形成位移；页面明确分别提供灰度版本、纯光照、建筑变体、测试场与制作过程。模块组合动画链接本次抓取失败；本次不声称观看过动画或对全部画面作视觉评判。

**采用的设计方法（推断/试验，不是历史证据）**：本轮在整体及街道视角之外，增加“去颜色也能读清主路/支路/门前过渡”的明度层级检查；保持同一建筑模块完整，用连续地表的低频差异建立场所，而不是靠更多装饰物掩盖重复。

**不采用**：不移植欧洲中世纪建筑、烟囱、装饰语汇；不因作者采用UE5/Nanite便升级技术栈或声称Three.js性能相同。作者自述的模块方法能作为流程对标，不能自动证明其方法适用于所有模型/尺度。

技术/审美分开：模块拆分与灰度检查是可实验的方法；本阶段没有核实奖项、玩家可用性或大规模性能，也不以作者职位/热度证明质量。

## 本轮具体修订门槛
1. 原14院位置、方向、scale1及近景几何不动；道路原走向不动。
2. 统一地面中区分通行带、低调路肩和各门前接入，不新增石板大道、亭台、水井、排水系统等未证设施。
3. 整体图检查道路连续性；近地视角检查门前接入是否读得清。若仅颜色变化或均匀大灰场，需诚实记为尚未解决的场所辨识问题。
4. 参考支持入口/围合的比较思路，不支持南组14院整体布局为东汉洛阳实证；全部新地表细节保持C标签。
