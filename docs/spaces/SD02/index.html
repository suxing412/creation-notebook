01 / 远景选路

先看到什么？

高仓以竖向仓体成为地标；低院以屋顶团和中央留白组织。场地与观看路线是原创比较装置，不是两种建筑曾共存的历史聚落。

02 / 接近前场

空地如何指向入口？

左支路接入仓前原路径，再折向侧梯。比较远看轮廓与近看进入关系；梯廊是由陶仓彩绘转成体积的推定，不是实测构造。

03 / 抬升俯读

围墙后还有哪层空间？

院门视角主要读门楼与外墙；抬升后看内屋、院心与内外通隙。房间是实心体块，不能当作已建室内游走。
