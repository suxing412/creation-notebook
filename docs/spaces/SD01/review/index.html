连接工坊 v0.3 · 从看展台到做观察

原型修订，尚非已验收空间设计。2026-11-02。

原版不足

原版全视口工坊能导航和查看资料，但连接关系始终固定，空间没有承载足够的观察操作。单加小地图不能解决这个问题。

目标统领

通过构件在同一场景中的变化，让访客比较转动连接与槽接约束。不是为了增加动效或完成点击数。

内容、空间与行为共同设计

  1. 转动庭：直接点灯体切换初始、收拢、展开三个已归档GLB样本；底座保留，观察臂段与铰轴关系。原子替换，失败保留旧样本。
  2. 插接廊：点中间隔板，逐级上提0、12、24、48、80、120mm；轨与其他隔板固定。侧向选择只解释槽口约束，不执行未验证位移。
  3. 自由探索、跳过、复位、资料始终可用。“已尝试”不等于理解测试通过。
  4. 相机相对平移、空间示意地图和近距观察服务于任务，不替代场景主体。

呈现表达与实现支撑

圆庭组织转动观察，线性廊组织插接观察。场景关系变化是内容，当前姿态/提升高度是状态，视觉变化和短文字是反馈。任务可跳过，资料不设解锁。近距观察由用户主动触发，按实际操作卡矩形保留可见区，退出恢复全景。

贯穿的验证与边界

离散模型状态与环境的CPU/BVH检查、状态和异步生命周期测试分别记录。原有环境内部19对包容关系未验；不称全部穿插归零。上提隔板是悬置观察，不证明稳定性。没有连续装配轨迹，也没有GPU、手机、动态闪烁或帧率验收。

对标与取舍

Bruno Simon原作者作品公开文字展示探索、交互、地图与复位入口。本次没有GPU实玩。采用动作—反馈—继续探索的结构，不复制素材，不为了技术标签增加车辆物理、天气、多人或WebGPU。

复用契约

只适用于相同构件层级、米制与已知姿态/偏移集。转动使用独立导出样本；上提要求中间隔板节点可识别，世界Y为竖直方向。新模型或新高度必须重做包络、支承、局部接触、相机及失败测试；不能从有限样本推断连续全集。
