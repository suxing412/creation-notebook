# 配方评审 · 一次真实失败后的修复

## 初次结果
三个预设并非换色。归一化后保持同宽，弦长 / 尾长 / 前缘曲率关系仍不同。初版沿用 Study 002 的 .023 铜边管半径。baseline 与 broad 通过，swept 出现 **4 对非相邻尾缘铜管自交**。输入在数值区间内并不意味着几何安全。

保留 `swept-before-validation.json` 和 `swept-before.png`。画面看起来还能用，但检测不通过就不能发布为合格。这是参数化比单件更严格的原因。

## 改进
把整个族的铜周边半径统一收细至 **.016**，而不是给失败样本塞一个隐藏例外，也不是删掉自交检查。复查三个预设。中脊与尾根保持原来装配语义，不为“零穿模”口号伪造制造连续体。

第一轮 48 sample beauty 的阴影噪点较明显；最终统一提高到 128 sample，仍不使用不可用的降噪器，不声称噪点完全消失。固定采样与显式 seed 0，避免不同图靠不同渲染预算制造质量错觉。

## 联网对照与反思
本轮重读 Three.js 官方色彩管理：线性材料数值不是 CSS sRGB，换浏览器后若颜色不对，不能只盲调灯光。把颜色空间约定、材质值、灯光比、相机和模型归一化一并纳入配方，而不只保存 mesh。

形态参照沿用原 002 已公开对标的 Igor Puškarić Orchid Manta 与 Johnson Martin Skye；本轮没有下载或复用其网格，没有谎称检查其底层拓扑。本配方目标是自己的抽象陶瓷翼壳，不模仿复杂飞船细节。技术资料与作者链接见 README 及原 Study 002。

不足仍在：尾根是嵌入式接合，侧面有独立件语义；未测整个参数空间；极小铜线在小屏可能只剩色线；没有真实 WebGL / 手机动态闪烁验收。下一次扩展形态族前，应先增加曲率自适应管径、相邻折叠检查及接触深度限制，不能直接放宽滑块范围。

## 最终图像观察与复查
已检查三件四视图并排图。宽展版弦深更浅、短尾；长尾版轮廓更深、尾长更突出。三件均未裁切，背面青色与瓷白分界可读；薄铜线没有重回粗黑裂缝感。侧面仍可看出尾根接合和装配层次，不能当作单体陶瓷制造件。128 sample 主图比初版更平顺，但暗部仍有残余噪声。

最终三个预设都通过：baseline 3925、broad 4068、swept 3959 对非共面装配相交，各 10 组允许关系；不是零穿插。四项非法输入均在输出前拒绝。相同环境重复 baseline 导出 GLB 的 SHA-256 一致，见 reproducibility.json。场景配置实读核验见 scene-audit.json。
