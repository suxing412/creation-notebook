# F01 · 对标来源与证据边界

初版生成器、HTML 和三章导航完成后，于 2026-11-01 重新联网检索并读取以下作者原站；没有下载、挪用任何第三方模型、截图、字体或贴图。

- [Bruno Simon 原站](https://bruno-simon.com/)：读取作者介绍、键鼠／手机操作文字、返回／复位功能和技术说明。其空间承担导航，而不是只展示一个对象；但本次没有实际驾驶，没有看见实时动画或测量性能。不模仿汽车玩法。
- [Bruno Simon HTML 版](https://bruno-simon.com/html/)：实际读取完整活动、项目和联系方式列表。这一信息等价的平面入口比“无法运行请换浏览器”更可靠。本作保留三个章节正文、模型与复盘链接，不把全文放进 WebGL。
- [Lusion 原站](https://lusion.co/)：读取工作室对设计、动态、3D 与开发共同形成叙事的说明，以及 Featured Work 分类列表。只读取文字层；没有检查作品 GPU 动画，不能据此比较视觉质量。`www` 版本访问失败，裸域可读。
- [oncyber 原站](https://oncyber.io/)：读取空间检索、模板、策展分类和创建入口；动态展厅本身未进入。只用于确认“空间也需要目录”，不声称见过其中展品或建筑。

由这些材料提出的设计推断：空间标识必须同时出现在场景和 DOM 目录，不能只靠一组外部按钮；非实时读者必须有完整的阅读路径。推断不是对参照作品实现细节的事实判断。
