00 / 序厅

让距离成为目录

左侧的深色石台收拢星轨的精密秩序，右侧暖色展台承接潮翼的连续曲面。中庭保留空白，让两件作品互相看见。中央玉色索引碑是序厅的空间定位标记，而非第三件展品；实时模式下点击它可返回序厅全景。

这是第一轮融合实验。三维不再只是网页中的展品，而是负责组织“去哪里、看什么、回到哪里”。三个目的地对应真实展厅位置、相机与文字锚点。

01 / 星轨档案

001 · AETHER RELIQUARY

绕行的秩序，
被包裹的光。

黄铜环带与玉色晶核形成层层嵌套的圣器。展厅用收敛的暗色背景与竖向金属边线回应它的仪式感，留出模型外轮廓的呼吸距离。

模型已修正退化面与共面重叠候选；宽金肋仍会遮挡晶核。装配接触不等于错误穿模，不能宣称全部穿插归零。

02 / 潮翼档案

002 · NACRE GLIDER

弧线，先于装饰。

陶瓷翼体以凸前缘和凹后缘建立流动轮廓，窄铜脊收束中心。展台从冷暗转向暖沙色，让材质和曲率成为主要信息，而不是用更多部件制造复杂。

尾根仍采用嵌接，不是连续焊接曲面。本页不将概念造型声称为可制造或可飞行结构。
