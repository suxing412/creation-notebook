01 / CONSTRUCTION

构造：观看之前

八片独立定轴叶片组成玄瞳。轴向分层使轮廓保持重叠，也保留叶片之间的间隙。在这个场景里，它被竖起为一扇概念门框：不是建筑构件，也不是可制造的快门。

镜头停在机械近景；叶片固定于原模型的 27.5° 姿态，不提供未验证的机械运动。这里的尺度是设计单位，不能换算成真实光圈值。

02 / APPROACH

抵达：把身体放进尺度

镜头退出近景，看到仪器与海岸观测所之间的距离。楼梯、入口与平台成为新的参照。空间导航不要求拖动模型寻找重点，而是让每个目的地对应一个清晰的问题。

这里的灰色基面是展陈语境，不是地形工程。两件作品并置，不假装它们具有真实的场地关系。

观测：建筑把视线交给远处

最终镜头靠近平台与屋顶装置，看向建筑而非模拟望远镜成像。仪器、身体、景观三个尺度由同一空间串联；文字始终留在普通文档流中，不被动画吞没。
