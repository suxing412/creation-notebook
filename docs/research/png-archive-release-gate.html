公开资产的元数据检查门

2026-11-02 · 造物手记工作法增补，不新增作品计数。

这次漏掉了什么

此前文字扫描覆盖了说明和脚本，却漏过 PNG 的文本元数据。公开 012 的图像以及尚未公开的 013 源包中，渲染器写入了含内部执行路径的 File 字段。网站显示正常、模型几何检查通过、源包 SHA 正确，都不能证明这些元数据适合公开。

修订后的发布流程

  • 按实际内容识别文件格式。 不只看扩展名；文字扫描、图像元数据检查、模型数据检查和交付文件身份检查分开记录。
  • 解析 PNG 的 tEXt、iTXt、zTXt。 处理相应压缩标志并解压压缩文本；检查关键字和值。解析或解压失败不是“未命中”，应标为未完成检查并阻止该文件被宣称已清理。
  • 按内容最小移除。 只移除确认不适合公开的路径字段或文本块。普通 Software、颜色、尺寸等合法信息不因同处文件而整体删除；不改画面、不重压缩 IDAT 来掩盖问题。
  • 证明无损并重新绑定身份。 记录清理前后 SHA、移除的块类型和关键字、IDAT 字节一致性及解码像素一致性。公开映射不写被移除的私有值。更新图像合同、文件清单、完整源包、分卷和还原校验；旧 SHA 不能替新文件背书。
  • 检查完整交付链。 站点资产之外，逐项检查源 ZIP 内的文件；若含嵌套归档，继续递归展开检查，或明确阻止未审嵌套归档进入发布。记录递归深度、大小限制及未能读取的成员，不把只扫 ZIP 外壳称作内部扫描。
  • 按实际新字节复验公开版本。 分卷实际重组完整 ZIP 并核对 SHA；部署、页面访问、图片身份和源包还原各有证据，再提升发布状态。设计验收、GPU 和手机状态不会因元数据修复自动提升。

本次修复的证据与边界

  • 012：38 张源包 PNG 的 IDAT 与解码像素保持一致；公开的 17 张 PNG 和身份合同同步更新。模型和网页逻辑不变。
  • 013：完整包中 16 张 PNG 均作前后无损核对，其中 13 张移除了命中的 File 文本块；几何、GLB 和 WebP 未因该清理改变。
  • 新源包作原始字节及 PNG 文本块（含压缩文本）独立复查，分卷完整还原验证与元数据检查是两项不同的门。
  • 清理当前公开版本不等于抹除了旧 Git 历史；本次不强推重写历史。旧原件和版本映射保留在适当的私有归档中。
  • 截至本记录，旧公开图像范围 336 个 PNG 命名路径中，已取得 300 个路径的对应字节证据；另 36 个大图仍未完成同字节审查。不得因此声称整个历史图库已经全部净化。后续补审应另记覆盖范围和日期。

可复用验收清单

  • [ ] 内容格式与扩展名核对；已列出实际扫描范围。
  • [ ] PNG 三类文本块均解析，压缩文本已解压，无静默跳过。
  • [ ] 源 ZIP 逐成员检查，嵌套归档递归或明确阻止未审部分发布。
  • [ ] 命中按字段最小修复；合法元数据未被无差别移除。
  • [ ] IDAT 与解码像素一致，模型与网页非目标文件保持原身份。
  • [ ] 新合同、完整包、分卷、还原结果和发布记录绑定同一版本。
  • [ ] 公开说明不包含私有路径值、参考原图或内部日志。
  • [ ] 历史残留与尚未审查部分明确列出，不把未发现等同于不存在。

这是一条特定格式的发布检查门，不是覆盖所有敏感信息、所有媒体格式或所有历史版本的形式化证明。
