003 玄瞳 · 网页设计 v2

修订日期：2026-11-01。模型未改；网页不是新增建模作品，也不是融合网页。

Brief / 一台可读的观察仪器

让读者先比较三个真实状态，再理解独立叶片的层次。保留精密暗色与黄铜色读数，不把禁用工具堆成主界面。概念位姿不等于光学 f 值或可制造机构。

成品后再对标

本轮修订后重新读取 teenage engineering OP–1 field 官方页（2026-11-01）。页面以具体部件／显示／接口的说明展开产品，随后提供使用资料；可借用“一个细节解释一个问题”的信息组织，而不是复制工业外观。本次证据为网页文本与图片说明，不声称体验过其动画、手机或实时画面。

旧页面的优点是状态与真实渲染相关联，缺点是手机要越过长主图才看到状态，禁用控件抢走注意力，角度不是 f 值的解释太远；结构 summary 缺少定制焦点，状态变化没有轻量播报。网页完成不等于体验验收通过。

已落实

三个状态按钮移到主图紧邻下方，状态、角度与图片 alt 一致；静态图片先预载，成功才切换读数，失败保留原图与状态。

当前状态用 polite live region；连续自定义滑杆更新不持续播报。没有伪造可用 GPU。

实时转角／材质／绕转收进原生 details；角度标签直接写“叶片转角，非 f 值”。Escape 关闭并回到 summary。

结构展开与画布明确焦点样式；已有真实接头渲染加入正文，解释分层而不声称完整联动驱动。

下载、建模复盘与网页复盘常驻正文，不依赖折叠面板。无脚本隐藏失效状态按钮、实时工具及加载提示，保留主图、三状态图版、结构图与链接。

增补方向键环视路径，减少动态偏好下拒绝开启自动绕转。保留原始运动四元数顺序，不触及模型及运动参数。

检查与复测计划

JavaScript 语法检查已通过；GLB 与 Blender 源文件和修订前公开版逐字节一致。44px 是主要控件的项目目标，不是“所有 WCAG AA 控件都必须 44px”；W3C 2.5.8 的基础尺寸为 24px 且有例外。

待集成端真实浏览器检查：320×600、390×844、768×600、1280×600 的横向溢出、三状态读数／图片、details Enter/Escape、无 JavaScript 静态路径。无脚本 iframe 只允许同源，不允许脚本，以免把不透明源的图片限制误当成产品故障。尚未声称真实手机、GPU、实时闪烁、200% 放大、完整读屏或键盘交互验收完成。

指定纯色色对计算：弱文字 #9ca59f 对面板 #181d1c 为 6.74:1；不代表所有图像叠字与状态都通过对比验收。

窄屏浏览器复查发现 WebGL 不可用说明遮住叶片下缘，已将状态说明移出图像为常显图下说明，不隐藏环境限制。

不足与下一步

三个离线状态不能代替连续运动；暗色图像上的细节可辨度还需要真机检查。新增键盘路径未经 GPU 执行验证。当前几何结构本身仍缺传动环与完整装配，不应由网页包装掩盖。下一次先据窄屏和键盘实测修错，再决定是否增加部件注释，而非增加更多按钮。

修订后实际浏览器验收

集成端于 2026-11-01 用真实云浏览器检查 10 个 iframe：003/004 的 320×600、390×844、768×600、1280×600 及无脚本模式；实际内容宽为 305/375/753/1265px（滚动条占宽），scrollWidth 均等于 clientWidth，无横向溢出。无脚本主图、图版或章节图成功加载，说明、文档及下载链接存在，无虚假可用控件；沙箱内链接可达不证明文件下载完成。

键盘依次选择收拢／展开／中间，等待状态更新后原子读取的 src、alt、标签一致，图片自然宽 900px。结构 summary 以 Enter 打开、Escape 关闭并归还焦点。图下环境提示已实测为 static 文档流，与主图不重叠。

仅上述范围通过；真实 GPU／实时闪烁、真机手机、200% 放大、完整读屏与全路径键盘仍待验。
