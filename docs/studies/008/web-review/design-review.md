# 008 网页设计修订

## 独立任务

让观者区分孔洞、视角遮挡与孔口间剩余实体，而非复制007的正侧内空投影，也不把005规格页换皮。主页面是可独立阅读的图版；模型作者的Three观察页另行保留，主页面不模拟其控制界面。

## 首版：先有可审结构

01:02 UTC完成明确占位原型，暂不开放任何模型下载。随后用模型作者的**拓扑修正基线**低采样图检查排版，记录在[首版实际截图](v1-desktop.jpg)。最初失败模型的孔壁绕序错误没有被当作合格资产；模型历史依次为首版失败→拓扑修正基线→造型与法线改进，详见原模型review。

视觉方向：暖灰纸面、细黑线、少量橙红索引。大幅整体与窄孔缘裁片形成不对称图版，右侧只列少量当前名义输入。首屏图版和双组选项完整可见，没有一屏大标题或自动旋转来替代形体。

## 从真实首屏发现并修复

- **问题：方图塞宽框，实体太小。** 首版整体图虽然未裁切实体，但两侧留白太大。改向模型作者申请独立1584×960宽幅CPU图；三预设统一wide机位，不各自放大。原方图仍完整保留，不伪装同一机位。
- **问题：孔缘窄条和参数比主图略高。** 首版截图中下缘不齐，导致控件看起来像漂浮。为三列设同一高度约束、收紧参数留白；小屏另按自然流排版。
- **问题：手机上解释文字把控件推后。** 小屏压缩引言，参数变为紧凑四列；320时隐藏辅助窄条，把宽度留给完整主图，正文仍完整解释；控件仍为原生44px按钮。宽320的CSS检查不能被称为实体iPhone测试。
- **问题：‘最小连料’一词过宽。** 按最终模型报告改成前/后孔口折线之间及孔口到外缘的净空下界，明确排除孔内壁全域最薄、测地距离、制造和强度。
- **问题：主图成功但局部失败会制造错误身份。** 新图、孔缘裁片、预设名、视图名、名义输入、原图与观察页链接作为一个请求，全部解码成功才提交。新请求失败只保留旧图旧值，并提供重试。
