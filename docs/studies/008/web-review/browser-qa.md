# 008 主页面原生浏览器验收

2026-11-02 UTC，最终64点模型包接入后，在云Chromium与唯一受支持预览服务中完成。原模型470文件保持原字节。本报告不是GPU、真机或完整无障碍认证；[精确输入SHA与逐项读数](browser-checks.json)单独保留。

## 实际通过

- **桌面首屏**：DOM可用宽1173、高761，主图底597px、控件底683px；主图与双组原生控件完整在首屏。scrollWidth等于可用宽，无横溢出。[截图](final-desktop.jpg)
- **九组图版**：透幕、横幕、曲幕×整体、孔缘、俯看全部实际切换；主图、孔缘裁片、标题、视角、名义宽度与aria-pressed同步。名义宽度分别360/540/280mm。
- **原生键盘**：Enter选择预设、Tab转到下一按钮、Space切换视图；首图失败后使用Enter重试成功。此为有限键盘流程，不是完整读屏检查。
- **历史与深链**：Back从横幕整体回到横幕俯看，Forward正确恢复；直接进入曲幕孔缘深链，标题与280mm输入一致。
- **连续切换**：原生快速点击最终落在透幕俯看，图像、标题和360mm一致。原生此项未强制网络乱序；逆序解码等竞态由独立模拟测试补充，不互相替代。
- **320 CSS宽度**：iframe外框320，滚动条后clientWidth305，scrollWidth305；控件底约600px。辅助窄条在此让位于完整主图。不是实体iPhone。[截图](mobile-320.jpg)
- **无JavaScript**：原生iframe sandbox未授予allow-scripts，增强类未启用、控件保持hidden；三幅静态图、三个预设、九个模型下载入口与原生章节锚点保留。实际点击章节进入三组比较。[截图](nojs.jpg) 此检查证明阅读与入口，不声称sandbox内下载权限测试。
- **真实HTTP缺图**：隔离fixture仅把横幕主图指向不存在路径，app.js/state.js字节不变。失败时保留透幕图、透幕标签与360mm，并显示重试。[失败截图](image-failure.jpg)
- **资源恢复**：将最终横幕宽幅原图按原字节放到该缺失路径，重试后主图、裁片、横幕标题与540mm同时提交，错误清空。[恢复截图](image-recovery.jpg)
- **首图404**：不冒称有上次成功图；主图及裁片不可用提示出现，正文与档案保留。Enter重试后真实透幕图恢复。[截图](initial-image-failure.jpg)
- **独立观察页入口**：从主页面真实链接进入原模型viewer；尝试正常3D载入，环境报告没有WebGL上下文，静态图、正文与下载仍可用。未改任何GL或浏览器安全设置。[截图](viewer-fallback.jpg)
