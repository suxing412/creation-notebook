# 008 · 复盘

## 本轮学到的具体方法

1. **透孔不能由渲染外观担保。** 原首版孔壁绕序错误，平均平滑法线仍能给出似乎合理的孔。局部绕序、真实孔壁环面和中心贯穿射线须单独检查；正体积与总体连通不替代它们。保留失败图和原报告，先修拓扑再谈美化。
2. **法线有两层身份。** 构造顶点/面绕序决定几何，custom face-corner normals决定光照插值。二者可能不同；本轮新增单位/有限/与面同半球检查和native→GLB角法向对应。存储重开存在小量化差别，以明确向量容差报告，不说逐法线精确一致。
3. **孔口节奏必须让位于材料余量。** 宽高、孔数、渐变和孔比要耦合；大孔口+高孔数不是仅调整一个滑杆。开发域余量用于输入拒绝，实际native孔口折线下界另算。两者定义不同，不能用一个数字替另一个。
4. **更密不一定更强。** 密化孔环可能缩小圆与弦之间的偏差、收紧采样下界，但不会凭空增加材料强度。报告实际采样距离、覆盖半径和保守下界，避免用“下界变大”营销结构改善。
5. **远景合格不代表近景足够。** 32点孔环在960²孔缘近景出现可见折段；用同一解析目标检查实际native边中点，最大采样弦误差0.1765mm；64点隔离试样约0.0455mm。该诊断只采每条边中点，不是连续最大误差证明。
6. **最终文件本身必须重审。** 中间候选/边界PASS，不给重新保存的native、更新的metadata或后来的导出自动放行。manifest显式映射最终identity报告，导入者不按历史文件名猜“最新”。
7. **模型身份与交付包装分离。** 下载标签/URL放delivery-links独立数据，raw源默认BLEND；托管投影变成单BLEND ZIP时只改交付配置和对应无JS链接，不全局替换模型尺寸、状态或元数据。

## 尚有不足

该家族仍是规则矩形单元，不是自由边界、任意多孔拓扑或结构优化器。圆柱曲面易控，但没有双曲率的参数化/厚度保证。外边框是连续直角端面，不是可制造软边认证；立于摄影地面不代表自立。GPU/真实手机未验，不能拿node loader和状态模拟填补。正式最终取舍及接受条件以gate-review和manifest为准；这份复盘不独立授予发布许可。

## 下一次可复用，不应照抄

保留严格输入、显式孔环/壁、世界体积、法向两层身份、有限净空定义、恶意反例、导出有向几何、原子图片状态和交付URL分离。**不要**把本族的行列数、圆柱逆映射或边界采样阈值直接套到下一形体，更不能新增一张整对接触白名单掩盖穿插。进入新family先写条件与停止项，而不是先复制PASS。
