# AETHER 001 · 网格质量检查与修订

本轮读取实际 Blender 文件进行审计，并重新生成模型、GLB 和多视角离线渲染。检查不是“看起来没问题”的代替，也不能取代真实浏览器中的转动闪烁测试。

## 确认并修复的问题

1. **赤道环重合封口**：闭合旋转截面被错误加上两张重合实心圆盘，形成精确共面并遮挡核心。修复为闭合截面环形连接，不生成端盖。
2. **闭合环管接缝**：原管道把起终点当成独立端面，环缝附近出现重叠。修复为循环邻接、共享接缝索引，不再封两张端盖。
3. **极点退化拓扑**：冠尖、底针和晶核以重叠顶点形成尖端，产生零面积三角形；晶核还有非流形边。修复为单一极点及三角扇。
4. **意外刻度穿插**：内星轨第 50 号长刻度与第 5 片肋叶相交。将该刻度缩短后再次跑 BVH，两者不再检出相交。未大改外观。

## 真实数据对照

检查项目：修复前 → 修复后

- 零面积原始多边形 → 3 → 0
- 零面积三角面 → 366 → 0
- 完全重合面组 → 1 → 0
- 共面且有正面积重叠的候选对 → 23 → 0
- 非流形边 → 20 → 0
- BVH 相交物体候选对 → 434 → 427
- GLB 三角面数 → 87,220 → 86,362

修复后仍有 **427 对 BVH 相交候选**，不能宣称“所有穿模归零”。按构件分为：星轨刻度与轨道/发光嵌线 240 对、底座装饰与基体 118 对、赤道环装配接触 26 对、肋叶珐琅嵌线 6 对，其余 37 对为肋叶端部与底座/冠件、金色经线在尖端汇合、悬挂线与端部连接以及晶核底针接触。它们按当前造型意图视为受控镶嵌或连接候选，不把“BVH 报数减少”当美术质量指标。

当前仍采用独立组件重叠装配，并非制造级布尔融合的连续实体。后续若做剖面、动画拆解或实体制造，应进一步处理接头实体关系，不直接复用此项通过结论。

## 不应夸大的边界

- 平面算法使用数值容差和凸面假设，不能证明任意极小间隙或所有非凸面无问题。
- BVH 不自行理解“连接”或“错误穿插”；保留候选需要结合构造意图及视角复核。
- 当前云端浏览器 WebGL 被禁用，**没有执行真实实时 Z-fighting 测试**。仍需在支持 WebGL 的环境中转动、远近缩放、切换光照复核；当前静态图不能作为闪烁测试证据。
- 多视角检查也确认了下一步美术问题：前景宽肋遮挡晶核，赤道区域投影偏密。记录为 P1 改进，不与本轮 P0 拓扑修复混淆。
