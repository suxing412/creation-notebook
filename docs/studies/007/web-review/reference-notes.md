## 1. 原作者档案：Barbara Hepworth / Two Forms (Divided Circle)

来源：https://www.barbarahepworth.org.uk/sculptures/1969/two-forms-divided-circle/index.php?sort=medium

- **文本实际读取**：作品页有作品名称、材料、年份、目录号、摄影地点与年份，以及按年份、目录号、材料、标题分类的入口。这里只研究其信息层级，不采用作品形状。
- **浏览器实际观察**：白色背景；左侧是短站点导航，中间狭列为材料目录，右侧大幅花园中的雕塑照片；照片完整占据主要视觉面积，图像同时呈现雕塑与后面的环境。目录很长，首屏图片下缘超出窗口。没有测试该站手机、键盘或加载失败。
- **推断**：明确图版身份和摄影上下文能避免把环境照片读作孤立规格图；但007只有三变体，机械照搬长目录会分散注意。
- **采用**：每张自有图版明确变体、视角、图像类型，原图链接留在图注旁。
- **不采用**：不复制两侧窄目录，不复制艺术家雕塑轮廓、作品名称或花园照片；不把原作者页面当007的模型依据。

## 2. 美术馆藏品页：Whitney / Isamu Noguchi, The Gunas

来源：https://whitney.org/collection/works/437

- **文本实际读取**：对象页区分作品图片、标题/年份、材料/尺寸/藏品编号，以及音频说明与展览历史。
- **浏览器实际观察**：黑白版式，左图右信息；高而窄的雕塑在左栏可辨，标题尺度远小于全站导航；右侧操作区独立；页面底部出现cookie面板遮挡一部分图像。此记录不评价其整体无障碍合格与否。
- **推断**：把“看作品”与“读档案”分区，比在图上压很多规格更利于观察。说明可渐进展开，但核心物体身份不应藏在折叠里。
- **采用**：007把投影身份与材质说明留在图旁，下载与门禁归档到第四章；完整无JS正文与原生details。
- **不采用**：不增加分享、收藏、票务、音频或cookie样式浮层，不把真实艺术家的历史和解释移植到原创模型。

## 3. 展览页：Whitney / Correspondences: Isamu Noguchi and Ellsworth Kelly

来源：https://whitney.org/exhibitions/correspondences

- **文本实际读取**：页面有展览标题、日期、Overview与Art & Artists分区；展览图片下有作品与摄影相关说明，正文说明策展人。
- **浏览器实际观察**：首屏由超大粗黑展览标题和灰色日期占主导，展览图像从较低位置开始，cookie面板遮住部分下方内容。没有滚轮劫持或自动轮播的测试结论。
- **推断**：这种标题优先结构服务于展览识别，但不适合007“首屏看形体并开始观察”的主要任务。
- **采用**：章节是独立阅读目的，不重复宣传语；用图号、简短标题和上下文建立展览感。
- **不采用**：拒绝巨标题将首图和主要入口压出屏幕；不复制全大写超重字体系统。
