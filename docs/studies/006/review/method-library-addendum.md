# 可移入建模方法库的006增补（本文件未修改其它目录）

- **对数值的尺度负责。** 双精度计算不能消除原始float32顶点量化。窄斜三角要保留真实专项漏检，并用双向平面距离、角阈值和移离控制组解释容差；不要把近共面阈值冒充GPU闪烁阈值。
- **检查坐标系一致。** 世界顶点包络配局部体积可能放过“局部镜像＋负变换＋全反面”。世界有向体积要单测；模板也可明确静态identity transform契约。005源码有同类局部体积逻辑，本轮不改冻结005，也不因此声称旧交付几何已坏。
- **raw mesh不是evaluated scene。** 若只检查ob.data，就明确拒绝修改器、shape key、约束、父子关系与动画/driver等未支持状态。实际反例要证明raw数组未变而渲染几何可变，再要求专用reason拒绝。
- **等法向厚度和网格厚度分开。** 圆弧偏移R±t/2可作为解析约束；离散弦面中点约t cos(Δθ/2)。提供站点与边中点的有限实测，不许把同名参数当实测证书。
- **圆角有方向。** 平面轮廓圆角、截面微圆角、端盖边圆角是不同几何。未做的方向不要靠光滑着色和亮边补称。
- **少件也要检查隐藏状态。** 单一连续壳体没有装配pair，完全包容岛仍会无表面交线；单连通和全顶点约束不能被通用BVH零计数代替。
- **亮点要定位到面。** 固定相机射线、normal/face来源与同几何诊断材质能解释局部高光；全局QA不能自动说明每个像素的原因。
- **成本按证据选。** 本轮先48/560²造型，再128比较，选256/960²上限；实际adaptive sampling、CPU线程和无降噪必须记录。残余噪声不装作材质纹理。
