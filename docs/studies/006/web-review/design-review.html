FOLIO 折页 · 006 网页设计评审

日期：2026-11-01。此记录首先创建于网页首版落盘之后、外部检索之前。后续修订须分别标记完成与待验。

本页独立目标

制作图解／技术编辑页，不是005暖纸产品图录的换肤，也不是尚未轮到的F03融合。以侧面路径→连续厚壳→同尺度三变体→可追溯源文件为阅读顺序。冷白、深蓝、细分隔线、有限等宽标注服务于形态的解释，不使用装饰性假尺寸、虚构工程箭头或AI模型图片。

首版（资产接入前）

已落盘语义HTML、原生章节锚点、深蓝截面章节、纵向变体列表、档案区域、跳至内容、可见焦点、响应式与减少动态规则。所有图版、数值、源入口均明确标为待接入；不使用不可用的假下载按钮。首版原始HTML/CSS只保存在本地before/，不会进入交付目录。

模型资产契约：folio / atlas / spire；连续闭合厚壳，m为源单位，mm为展示单位；model-info提供真实YZ中心线、边界投影、名义厚度、折角、半径、接地段；独立Three.js观察器由模型worker提供。网页不另造模型。

首版之后的检索与修订

首版存档后已完成nendo设计师、V&A博物馆和Vitra制造商编辑页检索。分别记录正文读取、实际浏览器视觉观察与设计推断；不下载外部原图进入交付。完整来源、访问日期与限制见reference-notes.md。

首版评审 → v2决定

  • P1 / 首屏读物偏晚。 根线程与本人实际看到1173×751首屏图版起于y287且下沿出屏。压缩mast/nav/hero上距，整体图使用contain，不靠裁切、负边距或overflow-x:hidden藏问题。
  • P1 / 技术图尚无来源层级。 由model-info的真实YZ路径和局部法向导出SVG，图号与弯段直接对应。分开名义输入、生成派生和离散网格检查，图例明确中心线、厚壳边界、说明标注；单位mm不混用m。
  • P1 / 只讲正确形状，不讲检查边界。 近景旁直接列本次检查与非制造结论，检查失败不能被页面美化为成功；源下载保留同哈希文件。
  • P2 / 三变体缺少可视比较。 用同一YZ比例尺的纵向条目，一列图像、一列差异、一列同字段数据；不另做滑动卡片或默认只显示一件，便于无JS逐项阅读。
  • P2 / 说明与工具容易混淆。 页内只有少量真实图版切换；所有制作证据保留原生正文，独立Three.js在另页。图像失败时保留上一张成功图与正确图注、原图链接，首图失败时不得虚构“上一张成功”。

参考来源、实际观察与推断完整记录在reference-notes.md。上述决定已在最终真实资产接入后完成局部浏览器复查，详见browser-qa.md；代码规则和CSS视口仍不能视为手机／读屏验收。

独立只读审查后的修订

另一worker只读源代码并用假DOM复现竞态，没有占用浏览器或修改模型。

  • P1：初始HTML图A未完成→点B→A成功→B404时，旧实现错误隐藏已加载A并声称无成功图。现用hasCommitted区分初始图完成与增强提交，保持较新请求状态不被旧事件覆盖；专项与其余10项测试通过。
  • P1：深色章链接hover被通用蓝覆盖，指定色对仅约2.02:1。增加浅蓝hover，不用额外粗体补救。
  • P2：B标号随SVG缩小，320宽初版实见细小。放大标注，不改变模型轮廓比例；旁列仍有完整文本含义。
  • P2：补B3局部SVG的源哈希、站点范围、投影参数与输出哈希；侧图旁注明不能展示X向宽度。
  • 交付门禁：非draft生成强制图、模型、测量、源与独立观察入口齐备且对应模型检查哈希；构建白名单包含web-source，排除测试副本和原始占位HTML。

独立审查确认：中心线→法向偏移的单位语义没有误把解析厚度称为全域制造保证；三小图固定同尺度；静态内容和details不依赖脚本。没有据此宣称浏览器或辅助技术通过。

交付管线的反例修订

第二次独立只读复核在隔离临时目录中发现三项问题：哈希工具可给失败目录写“冻结”清单；少数文件名黑名单仍漏过额外草稿与stdout文本；中途CRC损坏的ZIP会让旧导入被部分替换。它们不是页面视觉问题，却会破坏数字资产的可信度。

修订为：完整ZIP先校验提供的SHA256，逐条读取校验CRC并暂存哈希后才替换，异常回滚；交付文件集合必须等于原模型ZIP条目加明确网页、SVG和复检允许清单；冻结必须在目标目录重跑四道网页检查并确认报告通过。独立隔离重测确认原先三个反例均被拒，CRC损坏不再破坏旧导入。这些是管线测试，不冒称最终模型、浏览器或制造验证。

最终设计结论

主页面从明确占位转为完整真实资产与可复现图解，正文没有候选或待接入信息；深蓝局部、浅色整物与同尺度侧图承担不同阅读任务。保留首版、布局复评与最终首屏三张阶段证据。最终范围是独立制作图解与独立观察入口，不是005换皮、不启动F03，不代替完整无障碍、GPU或制造验证。
