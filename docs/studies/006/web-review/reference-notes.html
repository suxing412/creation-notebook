检索与观察日期：2026-11-01。先保存网页首版与实际首屏截图，再做本轮检索。参考的是解释方法、版式关系与证据层级，不借用外部作品图片或造型。

nendo / softer than steel（设计师原站）

原始源：https://www.nendo.jp/en/works/softer-than-steel-2/ ，项目日期2014.04。访问方式：web正文读取＋原生云端浏览器实际打开和首屏视觉观察。

实际观察： 首屏是黑白概念草图而非摄影；图下左列列作品名、客户和日期，右列短文以翻起、弯折、缠绕等具体操作解释形态如何产生功能。后续摄影单独列出，另有image/sketch入口和摄影署名。本次浏览器截图见横向滚动条，不能把简洁视觉自动等同于窄屏无障碍优良。没有测试原站所有图片切换或移动端。

判断／采用： 将006的每一个弯段关联到真实轮廓中的具体位置，使用动词标题和短图注，让人知道哪次方向变化形成托面、阅读面或支撑。图解与渲染分开，解释线不装饰成工程测量。

不采用： 不复制原站草图、照片、字标、作品造型；不使用巨大空白或“read more”隐藏唯一的关键说明。

V&A / Moulding a seat for Marcel Breuer’s Short Chair（博物馆原站）

原始源：https://www.vam.ac.uk/articles/moulding-a-seat-for-marcel-breuers-short-chair ，原站标注最后更新2024-04-17；关联展览为2017年展览。本轮不将展览误说成正在进行。

实际观察： web正文和浏览器均读取到先解释材料与工序，再说明视频具体展示的模具与压力过程。首屏为工坊照片、Watch标签和文章标题。拒绝非必要Cookies后，正文仍保留，视频区域显示需要第三方Cookie同意，故未观看视频，不宣称验证其制作内容、字幕或播放器。页面可向下滚动阅读工序。

判断／采用： 核心制作步骤不依赖动画或视频。006不必先启动WebGL才能理解路径、厚度和变体；原生HTML、SVG与真实PNG先交付阅读能力，Three.js只作为独立观察入口。

不采用： 不把层压木成型方法搬成金属制造结论。006只是几何与材料外观研究，不宣称板金展开、回弹、加工公差或承载能力通过。

Vitra / Every day, something new happens（制造商编辑访谈）

原始源：https://www.vitra.com/en-un/magazine/details/every-day-something-new-happens ，原站出版日期2022-05-25。访问方式：web读取完整访谈相关段落；未实际观察该页的视觉布局或动画。

实际观察： 页面按问题与受访者回答组织，讨论材料更换、制作失败、后续处理和评价矩阵；图像另有出处。叙述明确出现过初次失败与尚不确定的材料行为，未把最终外观等同于完整验证。

判断／采用： 006把“名义输入”“生成派生”“离散网格检查”三类数据分层，检查结果与实际限制相邻。公开前后证据、已改之处与仍未证实的范围，避免全绿通过徽章盖过问题。

不采用： 不迁移访谈中的材料、可持续或寿命主张；不因同为连续壳体就声称相同生产方式。具体几何指标仅以自己的冻结文件为据。
