FOLIO折页

一条路径，
四次转向。

将前缘、托面、阅读面与后撑，做成一件连续的厚壳。不是把薄片拼在一起，而是让厚度跟着路径走。

01 / PATH

先读一条线。

这不是手绘近似轮廓。每个点来自生成模型的真实YZ中心线采样；四个B标号对应四处弯段。

从前端走向后端

  1. B1
    落下，接住。

    前缘转向前托平段。

    +90°
  2. B2
    抬起，形成阅读面。

    前托平段转向倾斜阅读面。

    +65°
  3. B3
    回折，形成后撑。

    阅读面越过顶弯转向后撑。

    -127°
  4. B4
    展开，落到桌面。

    后撑与末端平段连续相接。

    +62°

角度是沿路径前进时的有向转角，不是夹角，也不是钣金折弯机设定。

DETAIL / CONTACT

接地，是几何问题；
稳定，是另一件事。

前托平段和后足属于同一连续壳体。这里看真实接点，保留几何接地与受力验证之间的边界。

模型 / 摄影场景 / 图解

模型文件只包含原创厚壳。地面、灯光和摄影机属于独立场景。蓝色图解来自同一份模型数据，但不是渲染图，也不是实物试验。

  • 形态：真实CPU渲染与三种几何。
  • 构造：中心线、法向偏移和实际网格。
  • 端部：4 mm仅为平面轮廓圆角；端盖厚度边仍是硬边，不称全方向倒圆。
  • 边界：无WebGL时也能读取，不假称实时通过。
