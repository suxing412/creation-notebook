# 010 网页首版后的联网评审

检索/读取日期：2026-11-02。首版：prototype-v1/index.html（占位信息架构，非模型交付）。此轮观察仅基于官方页面可提取的内容与栏目顺序，不冒充像素级视觉评审、用户实验或行业共识。

## 原始来源与真实观察

1. [Vitsœ · 606 Universal Shelving System](https://www.vitsoe.com/gb/606)：官方将 Dieter Rams 的 606 描述为可适应变化的部件系统，产品页明确分设 Introduction、Gallery、Structure、Shelves and prices、How to buy。首页另有安装说明和所需配件的交付说明。
2. [Vitsœ · 606 components](https://www.vitsoe.com/us/606/components)：部件页以可选结构与组件为组织单位，E-Track 等条目带具体尺寸；单架用轨条目明确限定 light loading，而不把部件介绍等同无限制性能保证。
3. [Muuto · Stacked Storage System Bookcase](https://prod.professionals.muuto.com/product/Stacked-Storage-System-Bookcase/)：官方页面分别提供 Instructions 与 2D/3D/Revit files 入口，系列中列出 Clips、Modules 等不同组件，并引向配置器。作者署名为 Julien De Smedt。

未引用外站图像、模型或代码；以上不代表奖项、可用性测试或“最优”排名证据。

## 首版不足 → 具体修订

- 首版只有一个大占位区，不能把器物与连接关系同时解释。修订为整体 / 分解 / 接点三联图；桌面同屏读关系，窄屏顺序阅读。只能用模型负责人实际输出图。
- 首版“读懂槽口”没有具体规则。修订写明两组互补槽方向、板厚与槽宽的关系；具体数值由冻结配置生成，并链接原始报告。
- 首版“复现”只有方向描述，没有资产入口。修订分开原生文件、GLB、输入与检查证据，状态不与制造许可混用。
- 静态顺序示意容易被误认成可装配演示。在分解图下紧邻标注“静态示意，不单独证明全过程运动”；最终按实际有限运动报告补充边界，不宣称承载或制造稳定性。
- 不采用电商配置器：本任务是理解三种有限几何与复用条件，而非销售或连续参数设计；大型配置器增加未经验证参数域与移动端成本。

## 可复用方法与成本

采用“完整观察组”作为状态事务：三幅图均解码、元数据通过严格结构校验后整体提交；任一失败保留旧图与旧文字。三幅加载占用高于单图，收益是观众不会在切换中把不同模型的槽口配错。只按需加载选中组三图；静态下方图版 lazy loading。这个取舍仍需实际网络与手机验证，不能以代码测试替代。
