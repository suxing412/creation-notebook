# 010 首版后的参照评审
检索/读取日期：2026-11-02。首版在查阅本轮参照前已生成。只读原始产品页面文字；未把网页文字抓取当作产品实物试用、完整视觉评审或流行度证明。

## Vitra — Toolbox，Arik Levy，2010
原始来源：https://www.vitra.com/en-gb/product/toolbox/1000

实际观察：官方列作者与年份，并强调工作用品易取、器物可移动收放。页面存在产品图/CAD入口，本轮没有使用其 CAD 或复刻其外形。

推断/采用：成熟产品先解释用途，而不是只展示几何。因此将本作从宽泛“收纳器”收紧为“开放式桌面分隔 / 纸册直立陈列概念”，明确没有底托，不能留住小物。保留独立隔板作为视觉分区，不增无验证的把手功能。

未采用：整件携带承诺；没有实体抓取、重量或强度证据。

## Muuto — Arrange Desktop Series
原始来源：https://www.muuto.com/product/Arrange-Desktop-Series
设计作者补充原始品牌集团来源：https://www.millerknoll.com/products/accessories/desk-accessories/arrange-desktop-series

实际观察：Muuto 可读取的产品描述强调可配置组合、建筑式表达，并区分托盘与盖的材质。部分页面内容为未展开模板，故不能声称已检查完整交互。品牌集团检索结果将设计者列为 BIG-GAME。

推断/采用：以重复部件和受限变量形成系列，而不是只换颜色。SLOT 的三种方案改变长、宽、高、隔板数与板厚；颜色继续服务构件识别。修订上肩为固定 18 mm 圆弧，使高隔板轮廓更缓和；这是自己的审美试验，不是来源直接证明其更好。

未采用：原产品材料、回收比例、堆叠功能或商业可用性声明；本作无材料真实性或叠放验证。
