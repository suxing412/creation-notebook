# 010 复盘：从“做得像”到“槽真的有空间”

## 设计目标
用两根纵轨 + 重复隔板形成开放的桌面分隔 / 纸册陈列数字概念。独立网页要解释装配关系，而非把这件开放底部器物包装成万能收纳盒。未放入书本替代真实承载证据。

## 首版 → 评审 → 修订

1. 首版为矩形隔板、较高俯视。`first-version/beauty.png` 与 `revised-preview/beauty.png` 是同分辨率、采样、灯光和相机的圆肩前后比较；这些是早期几何，不代表最终门禁文件。
2. 首版之后读取 Vitra / Muuto 官方文本（详见 references.md）：借鉴用途表达与模块组织，不借用模型。圆肩是自己的视觉推断，不借品牌替自己证明审美。
3. 修订采用 18 mm 圆肩；主图降低俯角，另保留实际接点及抬升 55 mm 的槽口近景，避免让主图承担看不见的装配证明。
4. 原生 mesh 底边在倒角后约有 -0.013 mm 偏差。先发现、再以整件网格最低点对齐 Z=0 修复；不把修改元数据当修复。新 cap 几何已不再复现相同偏差，但仍保留实际对齐算法和逐件偏移记录。
5. 真实下界配置暴露显式三角化 cap 的共线零面积三角，并使倒角产生大量微边/退化面。修为原生闭合凹多边形 cap，倒角后由 Blender 统一处理导出三角化。原失败 JSON、原生成器、旧检查器身份保留；坏二进制只留私有工作区，不进入公开包。
6. 上界检查看到一次 containment_uncertain。原因是完全位于目标 AABB 外的点仍进入 ray parity 不确定分支；检查器增加严格 AABB 外部排除，再重跑全部故障控制，不添加部件对豁免。

早期脚本还遇到一次 `tessellate_polygon` 返回索引而非预期向量的 TypeError；当时修正返回类型适配后才生成首版。最终方案不依赖这段显式 cap 三角化，因此该实现错误不被当作几何通过证据。

## 有限迁移

SLOT / SPAN / RISE 用同一生成器，改变长宽、高度、隔板数与板厚；不是只换色。外包尺寸与内部轨距区分。额外测量 lower / upper 两个复合边界，不宣称整个连续参数域都安全。新配置即使输入校验通过，也必须通过实际 mesh / 导出 / 接点门禁。

## 检查证据怎么读

- 输入异常拒绝只是契约验证，不是几何验证。
- 原生几何与 GLB 二进制结构、有向世界三角坐标多集分别检查；多集一致不等于索引拓扑同构或渲染相同。
- 槽口每个接点分别测板厚、槽宽、两侧净空、槽底竖向间隙；无“整对允许接触”的跳过规则。
- +Z 位移仅检查明确列出的 12 个离散位置，每次移动一块隔板，其他构件静止。不是连续扫掠或真实装配路径证明。
- 三款七视图为 CPU 渲染；网页/总览/部署/实际实时 GPU、手机验证为另一条证据链，不能互相替代。

## 仍不足

- 视觉形体克制，但无真实使用任务数据；纸册厚度匹配、单手取放、桌面倾倒风险均未测。
- 开放底部与端部意味着适用范围窄，不能宣称保持小件、固定书本或稳定受力。
- 材质只是两种不透明视觉语言；没有板材纹理、加工刀具、回弹、制造或强度模拟。
- 128 样本 CPU 图可见轻微噪声，保留原像素作为证据；没有用降噪/缩图掩盖接点。
- 精确几何门禁仍使用数值阈值与有限射线采样，不是形式化证明。每次新参数都要复检。

## 继承到下一轮
保留实际槽面测量、失败对照、源/检查器哈希绑定、同机位前后图；不迁移具体书挡比例到任意曲面，也不为追求“最新”升级已固定的软件。下一轮优先改善“用户能否读懂结构与用途”，而不是加装饰掩盖边界。
