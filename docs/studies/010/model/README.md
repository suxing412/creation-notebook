# 010 · SLOT / 栖格

桌面分隔 / 纸册直立陈列的数字概念。两条低纵轨与 3 / 4 / 5 块横隔板，以互补半搭接槽形成可读的节奏。底部开放，不是装零碎物的托盘；未做承载、防倾倒、材料、制造公差或实物装配认证。

## 内容与状态

- `assets/slot`, `assets/span`, `assets/rise`：每款原生纯模型、实际 GLB、带灯光场景、配置、几何信息和七个 CPU 视角。
- `source`：同一生成器、严格输入契约、独立 native / GLB / 装配 / 运动检查器和故障控制。
- `review`：首版、受控比较、引用、复盘与实际检查证据。失败的模型二进制不打包。
- `parameter-contract.json`：可变参数、不变量、适用边界与有限采样声明。
- 网页、总览集成、公开部署由独立流程处理；这个包不等于网页已验收。

## 重现

固定 Blender 4.3.2，Python 3。不调用外部 AI 或 API。

```sh
python source/run.py --config configs/slot.json --output fresh-slot
```

输出目录必须是新目录。`--geometry-only` 可先做几何门禁；完整重现默认 Cycles CPU / 128 samples / 960×960 / seed 0 / AgX / 无降噪。同一配置生成几何预期一致，不保证跨软件/硬件渲染文件逐字节一致。GLB 导出时导出的只有器物，不包含地面和灯光。`scene.blend` 单独保留可重渲染的灯光场景。

## 读图

`beauty` 低俯主视、`front` 正面、`side` 侧面、`top` 顶面、`joint` 局部接点；`exploded` 所有隔板沿 Z 抬升 120 mm；`joint-exploded` 抬升 55 mm 的槽口近景。后两张是静态分解示意。运动报告仅有限位姿碰撞采样，不是连续运动证明或制造装配保证。

所有整体视图共用相机参数；接点视图随第一接点位置平移。画面是 CPU 渲染，不是实时 Three.js / GPU / iPhone 截图。没有验证真实实时闪烁。

## 槽口与底面

名义槽宽为板厚 + 总横向间隙；纵轨顶开口到半高，隔板底开口到半高 + 名义竖向间隙。最终生成器在倒角后对每个网格做实际最低点对齐，避免把 0.013 mm 的负底边当作精确齐平；平移量逐件记录。实际中缝须按表面测量，并考虑两构件平移差，不以参数公式替代检查。地面位于 Z = -0.2 mm，模型底面为 Z = 0；该微小展示净空不是工程公差。
