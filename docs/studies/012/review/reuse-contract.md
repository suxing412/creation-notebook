# 禾仓·前场 — 有限复用契约
## 适用与不适用
适用：矩形高仓体、简单双坡顶、开放前场、短直木阶与窄廊的低面策略展示练习。参考标签为河南东汉明器，成品是原创空间转译，不是精确汉末城址/真实承重/消防或建筑施工设计。
不适用：多层复杂木构、圆仓、斗栱考据、围合院落、行走游戏完整碰撞体、任意曲面建筑；不得只改参数就声称都满足同效果。

## 不变量与三组样本
统一较窄屋檐、弧形分段覆瓦意向、粗糙非金属土木材料、架空支点、入口地坪连续。seed=0，无随机依赖。测试三组：
- A：宽4.2 深3.2 墙高4.6 前场参数4.0，右侧向阶梯、偏左入口、短前廊。
- B：宽5.4 深3.2 墙高4.2 前场参数4.4，左侧向阶梯、偏右入口、较长前廊。
- C：宽3.6 深4.0 墙高5.0 前场参数4.8，前向阶梯、延伸廊、更深开放前场。
这些为美术工作单位（几何可达试验按米理解），不是古代实测。单体/阶梯布局和场地空间都变，不仅换色。

## 变量边界
生成器拒绝宽不在[3.6,5.4]、深不在[3.2,4.0]、墙高不在[4.2,5.0]、前场参数不在[4.0,4.8]以及NaN/Inf/布尔值；只测过上述3个配置，不证明区间内连续全集。7级踏步、级高约0.1614、步深0.28、梯宽0.95、入口平台顶1.38与室内相齐。A/B前场路径0.85宽需90°转入梯脚；C0.95宽直入。未模拟角色胶囊、负重/推车或导航网格，不能声称玩法通行已测。

## 重现
Blender 4.3.2 / CPU Cycles，脚本 `scripts/build_granary.py`，配置 `configs/variants.json`，64采样1200×1000；`--no-render`只重建保存，不出新图。`check_granary.py`原生拓扑，`check_contacts.py`共面与接触候选，`export_compare.py`实际导出再导入，`test_parameters.py`边界与路径算术。CPU/渲染时间按机器变化，不保证固定成本。材质为常量PBR，无贴图下载。

## 展示条件与验收
近景可看陶质分段、墙厚和阶梯；斜俯视主要读仓体/屋顶/前场与路径。顶视只查布局，尚未绑定最终SLG镜头、LOD、单位规模、地图性能预算。GPU真实闪烁与iPhone未验；数学/CPU图不能冒充实时验收。继承岬界的紧凑场所/路径层级，不采用其石拱、望远镜与全白风格；继承作者战役地图大形与路径可读性，不复制模型。
