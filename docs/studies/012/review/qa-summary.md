# 检查口径
- 原生模型：逐对象退化/重复面、边界/非流形边、有向边绕序、世界有向体积。身份见native-granary.json。
- GLB结构：自写检查器核对文件长度/块/accessor范围/有限值/索引边界/内部依赖；不是官方Khronos验证器。
- GLB几何：实际导出后重新导入Blender，世界空间顶点近邻1e-5美术单位归并，三角仅循环置换可等价，反向不等价；逐件最大误差和有向三角集合见export-consistency.json。不是材质/GPU等价证明。
- 共面：1e-6平面容差、投影交叠面积>1e-8阈值检查同向面；反向面对接另列，不把所有共面当闪烁。有限容差不是动态闪烁验收。
- 接点：BVH只给候选，每个三角交边点继续检查局部接触带；屋顶瓦脚、脊带、侧梁踏板、楼板与墙等分别限制，不因整对有合理嵌接就免查外露。疑似凸齿经像素射线确认为平台厚边/梯宽交接，并非侧梁穿顶；另做侧梁竖切收口，两者分开记录。
- 未证明：包含型穿插的全域排除、连续参数全集、所有相机运动净空、游戏物理导航；本模型静态无运动构件，不能用“运动净空通过”混淆。
- 手机、真实WebGL/GPU实时闪烁未验；云浏览器限制不绕过。
