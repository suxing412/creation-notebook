02 / 无脚本也能完整还原

下载以下全部分卷、身份与顺序清单 manifest.json以及Python 标准库还原脚本 restore-source.py，放入同一个新文件夹。保留文件名，勿手工改顺序。请从该文件夹运行：

python3 restore-source.py manifest.json --output source.zip

Windows 可将命令开头换为 py -3。无需安装依赖或联网。脚本逐卷验证大小和 SHA-256，完整 SHA-256 正确后才发布输出；默认拒绝覆写已有文件。缺卷、破损、错序或完整哈希不符会失败，不会留下冒充成品的 ZIP。输出目录须支持硬链接，否则安全失败，不降级成覆写。
