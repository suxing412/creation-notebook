# Study 004｜一手建筑参照与原创转译

研究日期：2026-11-01。仅浏览作者／建筑事务所公开项目页；实际查看原站照片与图纸。选择依据是本题的可比性，并非“世界最佳”排名。参考图片仅在 临时研究目录检视，**不进入交付物、不作为贴图、不复制模型**。

## 1. Snøhetta — Under，Lindesnes，2016–2019

一手来源：[事务所项目页](https://www.snohetta.com/projects/under)。实际查看页面首图（文件名 `2016226_OS_N175_webimageland.jpg`，岩岸风浪中的斜置体块）。

- **可核实证据：**原文说明单一长体量部分沉入海中、落在海床，厚混凝土壳面向岩岸。照片可见一个明确的建筑轮廓与尺度更小、方向错杂的岩层形成对比；接触处有岩块遮挡，不是整齐水平的“摆台”。
- **对本作的转译：**观测塔保持唯一高点，低平台和楼梯服从塔体；岩石采用主岩脊＋次级破面，不平均撒碎石。基础局部切入岩体，至少两个视角能读出平台、垫基、岩石的接触与遮挡。
- **证据局限：**首图有浪花、雾气和局部遮蔽，不能据此判断基础构造、锚固细节或精确尺寸。它是混凝土海洋建筑，不是砌体拱结构；本作不可照抄斜置外形或宣称同等工程真实性。

## 2. Bofill Taller de Arquitectura — La Fábrica，Sant Just Desvern

一手来源：[事务所项目页](https://www.bofill.com/projects/la-fabrica/)。实际查看首图 Image 15、改建期黑白照片 Image 13，以及网页标作 Plan 01、图面标题实际为 **SECCION C C** 的剖面图。

- **可核实证据：**原文明确写到在筒仓中加入楼板和螺旋楼梯、从混凝土墙体切出窄拱窗与门。竣工照片中圆柱体高低有序，窄洞口衬托实体墙的重量；改建照片展示斜向外楼梯与平台连接；剖面可区分墙厚、地面、上层与贯通空间。
- **对本作的转译：**用“重实墙＋少量深洞口”而非贴面拱纹表达砌体。拱底必须真实贯通、有可见内壁及拱圈厚度；阶梯必须到达有足够站立面积的平台，再连接拱门或望远镜。建筑大形应先于砖缝和金属小件被读到。
- **证据局限：**La Fábrica 是工业混凝土改造，拱形开口不等于传统楔石承重拱。黑白照片中的楼梯处在改建阶段，不能直接用作最终安全通行标准；剖面不是本作可照搬的平面或尺寸依据。

## 本作可执行验收（设计判断，非来源原话）

1. **体量：**缩略图仍能分清主塔、低平台、登临路线、岩座四级；青铜望远镜是次级焦点，不与建筑争同等体量。
2. **开口：**以低机位或背光侧视证明拱门“洞内有空间”；不可用黑色平面伪装孔洞。拱圈与墙身连接，拱脚落在有厚度的支承上。
3. **动线：**从最低一阶连续走到望远镜平台；阶顶不穿墙、不突然终止；中间平台与门口对齐，头部净空不被拱顶或楼板截断。
4. **落地：**侧／背视不得出现整栋悬浮或岩石穿过楼梯踏面；接缝的暗部来源于几何遮挡，而非一圈均匀涂黑。
5. **原创性：**只借鉴比例、空间负形与地形接触原则；本作自建砌块、真实拱洞、阶梯、岩石与望远镜，不复刻两项目外形、纹理、图纸或摄影。
6. **真实性边界：**几何连通、视图核验可以确认；抗风、砌体受力、基础安全未经工程计算，不作工程合规声明。
