# 004 岬界 · 网页设计 v2

修订日期：2026-11-01。使用既有最终模型与真实离线图；不新增或重设计模型。

## Brief / 把建筑看成一段路径
以冷纸色、蓝灰文字和有节奏的图文构成空间编辑页面。主线是抵达→登阶／门廊→观测，不是把七个按钮换七个名字。项目为建筑形态习作，不是施工、结构、光学或通行合规设计。

## 成品后再对标
修订后重新读取 [David Chipperfield Architects / Neues Museum](https://davidchipperfield.com/projects/neues-museum) 官方项目页（2026-11-01）：文本把房间序列、楼梯与材料放回空间关系中，并附分层平面说明。借鉴的是“图像承担空间问题、文字解释关系”的方法，不复用项目图片或暗示两件建筑具有同等专业水平。证据仅为网页文本与图像说明，没有声称实际体验原站动画或逐张查看所有图片。

原网页七个同级按钮混合了光照、视角与细部；读者可以切图，却不理解进入顺序。弱文字色约 4.10:1，状态字偏小；源文件已有，但网页设计复盘缺常驻入口。

## 已落实
- 主观察台分为“光照总览”与“形体检查”，保留日光／薄暮及四个实际视角。当前图片单选逻辑明确，实时模式说明其独立光照。
- 三个独立章节使用实际抵达修复图、门廊细部图、侧面图；每章都有空间问题与诚实图注。观测章明确侧面整体不是望远镜特写，没有用 AI 图冒充模型渲染。
- 历史 arrival-before 与当前 arrival-after 在专门证据区并列；旧缺陷标为历史而非当前效果。
- 增强正文和说明的色彩对比，采用正常文档流；主要按钮至少 44px，下载链接至少 60px。44px 是项目建议而非 WCAG AA 一刀切要求，参考 [W3C 2.5.8](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)。
- 实时控制收进原生 details；支持 Escape 关闭、summary 焦点，增补画布方向键环视。减少动态偏好下不启动自动环视。
- 静态切图先加载成功再更新图片／选中态／说明；失败保留上一有效图。无脚本隐藏死按钮、实时控件与待检测提示，章节图、文字、下载和两类复盘仍可读。
