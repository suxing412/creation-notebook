# 004 · 岬界 LIMEN

原创海岸观测所建筑练习。63 个网格构件、16,232 三角面，GLB 941,012 bytes。用实体墙与少量深拱洞建立体量，再通过岩岸、阶梯和望远镜平台组织抵达路线。

## 实际修订
- 修正布尔刀具法线，让拱门真正贯通；用门洞射线复核，而不是只看立面图案。
- 地形由随意嵌入改为开挖，让踏步与平台之间有连续可达关系。
- 最低立板仍被岩石局部穿出；降低开挖边界后，32,643 条立板水平射线中的异常从 96 降到 0。修改前后使用本作真实渲染对照。
- 最终主图、各向视图和抵达图已重新渲染。72 组有意装配接触仍保留，不宣称全模型无相交。

## 已验证与尚未验证
网页昼间与暮色的实际静态切换已检查。测试环境未能启用 WebGL，实时光照、绕转深度闪烁和真实手机帧率仍未验证。

名义米制只用于比例一致，不是建筑规范、结构受力、地基锚固或无障碍合规证明；海岸风化与砌筑材料仍偏抽象。
