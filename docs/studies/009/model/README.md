# 折光 HINGE · 造物手记 009

原创单平面折臂数字台灯，研究真实孔销、局部嵌接、三关节姿态与有限运动净空。三种几何变体共用生成器、转轴/孔径、材质、米制尺度和摄影；不是换颜色。它不是可制造或可持姿的工程灯具，没有电气、线缆、光通量、负载、摩擦或防倾倒认证。模型以未点亮状态在工作室灯光中展示。

## 三变体与有限姿态

- Hinge：235/245 mm两臂、105 mm底座半径、65 mm灯头半径。
- Reach：205/285 mm两臂、115 mm底座半径、75 mm灯头半径。
- Poise：280/210 mm两臂、95 mm底座半径、52 mm灯头半径。

每款default取各自config；folded固定角 `[100,-125,20]`、extended固定角 `[55,-70,-25]`。它们是收拢/展开样本，不是最大可动极限。三个角依次为肩部世界角、肘相对角、头部世界绝对角（度），不是三个世界角。必须从各资产model-info的pose读取实际姿态，config中保留生成器基准默认值。

模型Z向上、GLB `(x,y,z)→(x,z,-y)`。每构件世界坐标已烘焙、对象矩阵为单位；真实圆孔不是黑色贴图。`rigid_groups`记录相应转动刚体组。默认资产有6张960²/128样本Cycles CPU图，两个姿态样本各有同一front机位CPU图与真实BLEND/GLB。照片场景`scene.blend`与纯模型`model.blend`分开。

## 有限家族的复用条件

两段臂长接受范围200–280/200–290 mm，底座半径85–120 mm，灯头半径52–75 mm；关节角接受范围55–100/-125–-70/-25–20°。这是输入边界，不是连续全域无碰撞保证。组合姿态还要求灯头包络到Z=0面保守下界至少40 mm，否则拒绝；最终仍须对新模型重新几何审查。

不变量：轴沿Y、板材分层中心Y=±9 mm、主板厚12 mm、头颈板厚8 mm、孔名义半径4.5 mm、销半径4 mm、真实96段曲面、0.65 mm三段边倒角、固定局部接触规则、工作室/材质/种子0。长短孔板共享坐标按1 nm量化，避免原先拼接浮点裂缝；这不是1 nm制造精度声明。固定板间Y间距在声明的平面旋转下不变，但不证明其它构件都互不碰撞。

不适用：任意三维旋转、弯臂、异形轴孔、非平面机构、超大/超小尺度、修改材质后仍假定同画面、真实载荷和电气产品。每个新组合先接受配置，再造真实网格，再过导出/装配/运动门禁，再看多视角；其中任何一步不能替代其余步骤。

## 复现

Blender 4.3.2、自带Python；外部Python3用于调度/打包，Pillow只做无损PNG元数据清理。Three r180仅用于GLTFLoader真实字节解析，MIT许可在vendor。只使用新输出目录：

```sh
python source/run.py --config configs/hinge.json --output rebuilt/hinge
python source/run.py --config configs/hinge.json --output rebuilt/folded --angles '[100,-125,20]'
python source/test_contract.py
node source/test_three_loader.mjs
```

新文件要重跑新报告，发行清单不自动授予重建文件PASS。原生BLEND容器时间等可变化，不保证重保存文件逐字节相同。固定CPU/版本/参数可以复现几何和视觉条件，但不保证不同CPU逐像素一致。

`review/research-and-iteration.md`记录作者来源、采用/不采用方法与首版问题。`review/qa-*`保留检查器自身反例和修订，最终有效报告入口见manifest。检查均绑定实际文件与检查器SHA，历史失败不改写为通过。

GPU、实时动画/闪烁、手机触控未验。独立网页另行交付，本包不冒称已发布网站。任意BVH三角候选不是“穿模错误数量”：接头只在明确空间区域接受，区域外同一构件对仍拒绝；不能声称全部穿插归零。

## Three.js 刚体复用接口

`source/pose-three.mjs` 提供 `calculatePose(config, angles)` 与 `applyPose(gltf.scene, baseInfo, angles)`。它在真实默认GLB上施加世界刚体矩阵，每次从基准姿态重新计算，避免连续切换累积误差。Three坐标轴转换在模块内部处理。验证使用三款×展开/收拢/回默认/再收拢，与分别从Blender重导的实际GLB进行双向顶点位置集合比较，容差0.2µm；这不等于索引拓扑或三角对应证明。首次索引顺序相等的错误假设已记录，正式native/GLB有向三角多集一致性由独立门禁另行检验。

```sh
node source/test_three_pose.mjs
```

Three矩阵/加载器只在CPU执行，不是实时GPU动画验收。此接口也不实现碰撞求解、关节约束、载荷或自动寻路。孔销间隙是数字装配尺度，扩散片保持/密封与真实摩擦紧固件未建模，不能据数字摆姿制造实物。
