## Anglepoise / Type 75，Sir Kenneth Grange
来源：https://www.anglepoise.com/product/type-75-desk-lamp-jet-black/
实际观察：原生页面首屏将大幅产品/场景图和产品名称、颜色入口并列，左侧缩略图列包含多种摄影和尺寸图。DOM及网页正文另分 Product Specification 与 Downloads。技术资料与生活场景的用途可分辨。
迁移到本作：把几何变体与姿态样本分为两个选择组；统一 front 机位用于比较，beauty 另作造型欣赏，避免缩略图类型混用。下载与证据资料单独分区。
不采用：购物、价格、库存与保修内容不属于原创概念模型；不复制弹簧结构或品牌审美外形。商业产品成熟度不是本作品的安全认证。

## Artemide / Tolomeo，Michele De Lucchi、Giancarlo Fassina
原始技术表：https://www.artemide.com/contents/pdfcache/artemide_tolomeo_table_led_2700k_body_lamp_aluminium_4677412_en.pdf?j1776030980046=
原始区域站页面：https://www.artemide-benelux.com/en/product/modalProdotto?id=1849863
实际获取：检索文本可读技术表把静态尺寸与最大延伸尺寸分别列出，产品页把二维/三维/光度文件分开。区域页二次打开超时，未声称完成该站原生视觉评审。
迁移到本作：分开输入臂长、实际选中姿态的灯头中心坐标和有限验证范围；不能把一个姿态的坐标称为最大伸展范围。下载标明文件用途。
不采用：电气、照度、稳定性、弹簧平衡数据无本作实测，不填虚构规格。奖项与审美认可不等于我们的交互可用性，未用奖项给本作背书。

## 初稿不足与修订
1. v1 把初稿 beauty 图放在姿态主区，不能公平比较姿态。修订为所有姿态统一 front 正交摄影，造型图独立。
2. v1 把角度合并为一行，可能混淆相对肘角和世界角。修订为三个独立具名行，并解释相对/绝对参考系。
3. v1 只有泛泛的三段口号。修订为真实9个样本图册、参数对照、失败历史与复现入口。无脚本也保留图/值对应关系。
4. 继承008事务式状态：只有图像decode和对应元数据均成功，才更新图/参数/选中状态/历史。失败保留旧图旧值；过期请求不可盖写新结果。下载映射隔离，不改异步逻辑。
