# 005 · Vesper / 暮灯

一组原创、受约束的参数化桌灯研究。偏心椭圆软罩、内缩发光透光体、轻微 S 曲线支柱、圆角椭圆底座构成同一视觉语言；三个变体改变**宽深比、罩拱高、整体高度、支柱偏移和底座比例**，不是换色。

## 文件与复现

- `assets/{hush,poise,reach}/model.blend`：只有 8 个灯具构件的真实 Blender 文件。
- `model.glb`：同一模型的 glTF 2.0 二进制，无外部贴图/资源。
- `scene.blend`：固定摄影棚、灯光、材质与真正离线渲染场景。
- `beauty / front / side / top / junction / base-junction.png`：真实 CPU Cycles 渲染，不是假实时截图。
- `model-info.json / validation.json / glb-validation.json`：尺寸、参数、接触和文件检查。
- `manifest.json`：供独立网页消费的相对路径契约。
- `review/`：初版、复检、官方资料查阅与有范围的复盘。

只在 **Blender 4.3.2** 验证。Python 3 包装入口需要 Pillow；Blender 内置 Python 无额外建模依赖。版本/输入异常直接拒绝；无外部 AI、下载模型或贴图。

```sh
python source/run.py --config configs/poise.json --output my-poise --threads 6
python source/test_contract.py
python source/test_all.py --output my-qa-run --threads 2
```

入口拒绝覆盖已有目录。暂存几何预检（失败即停止，不耗长渲染）→ 同配置全量生成 → 图像去辅助元数据 → 重开 `.blend` 静态几何/装配门禁 → GLB 结构门禁 → 无私有路径标记检查 → 才复制到目标目录。直接使用底层 `generate.py --geometry-only` 只是待验临时模型，不是交付状态。

## 固定条件与可变量

固定：recipe **1.1.0**、seed **0**（几何不使用随机数）、角向 128 段、罩径向 28 段、封闭极点/环形拓扑、材质、相机、灯光、色彩、6 mm 罩体垂直厚度、4 mm 透光体垂直厚度、透光体径比 .86、罩缘参考垂直偏置 16 mm、三根定位销、26 mm 底座高。

可变量的范围和实际三个配置见 `config.schema.json` 与 `configs/`。单位为**米**，没有最后按包围盒归一化，网页可显示真实建模尺寸。

| 输入 | Hush 低阔 | Poise 均衡 | Reach 窄高 |
|---|---:|---:|---:|
| 罩名义宽 / 深 mm | 480 / 300 | 410 / 320 | 340 / 285 |
| 罩拱高 mm | 57 | 84 | 113 |
| 罩缘高 mm | 300 | 390 | 515 |
| 柱总偏移 mm | 30 | 45 | 60 |
| 底座宽 / 深 mm | 200 / 150 | 185 / 145 | 165 / 140 |
| 冠部偏心 mm | 18 | 14 | 10 |

实际宽度包含真实圆角外扩，与名义罩宽略有不同；以 `model-info.json` 为准。厚度按 Z 方向定义，**不是全曲面的等法向壁厚**。

耦合拒绝条件：罩宽深比 >1.7、罩拱高/宽 >.36、罩缘高/底座宽 >3.3。最后一条只是造型支撑感边界，**不是抗倾覆证明**。范围是输入接受域，不是全八维域无自交保证；新组合还必须经过全门禁与人工多视图评审。两个全低/全高组合已实际检查，不代表 256 个角点或连续域都已覆盖。

## 构造与接触政策

8 个闭合构件：罩、透光体、底座、柱、圆角套筒、3 根定位销。柱在底座/套筒内小量嵌接；套筒顶端留在罩厚度之内；销的两端分别进入套筒和透光体。它们是明确的静态装配关系，不假装统一焊接成制造实心体。

**28 对构件全部有逐对结果**：仅 9 对指定装配接触，其余 19 对必须分离。接触候选需落在规定空间区域，端点还必须在目标实体内部且处于规定近表面深度；不能把整类“支撑件”放行。

门禁还要求每个语义构件恰好一个连通分量，隐藏 pin/hub 的所有顶点均落在各自有限解析包络；这不是“单连通即无自交”的论断。

门禁：退化三角形面积 <1e−12 m²；世界坐标 1e−8 m 重复三角形；边非二流形；局部面绕序不一致；非正有向体积；BVH 非相邻自交；双精度平面运算 + 相邻/反向法线桶搜索 + 正面积 SAT 共面重叠；意外接触/丢失接点/区域越界；采样完全包容检查；装配端点嵌深。

限制：BVH 共享顶点相邻面不作完整折叠证明；射线包容和最近面净距为离散采样；平面分桶不是精确符号几何。报告的最小距离是**采样最小值**，不等于解析的全边全点最小距离。它们是可复验门禁，不是任意网格的完美证明。

## “同样效果”的准确含义

在这些固定材质、摄影与构造规则下保持同族的柔和罩体、深色支撑、可读的实体分层和统一展示，不保证每个形状同亮度、同像素或自动获得同样审美质量。

- Cycles **CPU**，固定 seed 0，AgX，sRGB 显示，曝光 −0.4，gamma 1。
- 主图 900×1000 / 1024 samples；正交辅助 840×840 / 384；接点 1000×800 / 256。
- 当前 Blender 构建没有可选 Cycles 降噪器，故**未降噪**；不把去噪或采样改动说成几何修复。
- Beauty/front/side/top 的相机、取景、灯光与曝光跨三变体固定，保留真实尺寸差异。junction 随各变体的罩缘定位，base-junction 随柱脚定位，**局部近景不可用来比较跨变体尺度**。
- 纯模型是 metric Z-up；glTF 导出器转换为 glTF Y-up。网页应按 GLB 的空间使用，不再次旋转成 Z-up。
- GLB 保留几何、PBR 和发光参数；不包含摄影棚/灯光。乳白透光体在本研究中是扩散色 + emission 的视觉代理，**没有校准光谱、透射散射或流明**。Three.js 灯光、色调映射和实时算法不等于 CPU Cycles。

## 尚未承诺

WebGL、GPU、动态绕转闪烁、真实 iPhone **未验**，不修改浏览器 GL 安全配置。没有电路、充电、热管理、线缆、开关、防倾覆、承重或安规制造设计；不可按本模型直接生产通电灯具。

初版错误与修复见 `review/reflection.md`。`review/first-version/` 故意保留被拒绝的历史模型，不能当作最终可用资产；最终三件只在 `assets/`。官方来源只借鉴分层光路/材料分工的方法，不包含其图片、模型或形体数据。
