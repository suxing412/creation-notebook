独立目标

产品规格图录，而非 001–004 的另一种模型查看器。阅读顺序为：形态家族 → 并置比较 → 结构证据 → 固定条件与可变量 → 可下载档案。暖纸底、深植物绿配方章节与焦橙强调，英文大字和中文短句建立节奏。

首版范围

已具备语义 HTML、三列/窄屏单列排版、跳至内容、锚点导航、减少动态与打印规则。真实模型图、三组精确参数、下载源、执行过的复现命令均未接入；所有占位明确标记。没有伪装成已完成的按钮或虚构性能数字。

接下来的评审

在首版落盘之后访问原作者/厂商的真实网页；记录实际读到的内容与未能验证的交互、观察与推断、采用与不采用。随后修订、实资产接入、复查与前后对照。

首版之后的真实网页检索（2026-11-01）

Flos / Bellhop Unplugged（厂商原站）

URL：https://professional.flos.com/en/global/product/bellhop-unplugged-f1130030/

实际读取：具体产品编号下有技术图、主要参数、光学、电气与尺寸分组；下方按技术说明、安装、光度、2D 与 3D 分列下载。浏览器确实打开原站，首轮出现 Cookie 同意层；拒绝非必要 Cookie 后继续观察。页面中有与该型号对应的产品图，不是仅一张氛围照片。

判断/推断：分组让设计阅读与工程查证使用同一入口；下载以文件用途命名比泛称“资源”更清楚。这是信息架构判断，不是该站用户研究结果。

采用：将 Vesper 的几何规格、渲染条件、工程边界分开，下载按 GLB / Blender / 生成源 / QA 命名；做一个相同字段的三变体矩阵。

不采用：不复制其外观、产品图、文字、商标，不给原创研究套入功率、IP、防护等级等未经测试的商业灯具指标；不增加商店、询价、通讯订阅等无关步骤。

Muuto / Ease Portable Lamp（厂商原站）

URL：https://www.muuto.com/product/Ease-Portable-Lamp

实际读取：正文包括产品叙述、单独的尺寸字段、材料、事实表、使用说明、packshot/lifestyle 图与 2D/3D/Revit 下载分类。文本抓取也暴露未渲染模板占位符，并出现内容不相符的桌面护理说明；不能把抓取输出当该站全部视觉质量的证据。本次未宣称完成其交互、移动端或动画验收。

判断/推断：图片类别与下载格式分开有助于避免把氛围照当规格图，文案—型号一致性需要人工复核。

采用：明确 beauty / 正交 / 接头细节各自用途；网页每个尺寸均来自同一版本的 model-info，而非手写估值。给局部渲染配对应构件说明。

不采用：不使用未经验证的真实场景用途承诺，不复制其营销修辞或视觉资产，也不把品牌商业产品的电池、光学数据迁移到模型研究。

Wästberg+ / Pawson W223（厂商原站）

URL：https://www.wastberg.com/en/collections/pawson-w223

实际读取：集合页将 Discover、Specs & Downloads、Gallery 分开；材料说明讨论重量、纹理与材料对光的不同反应，图集逐张署名摄影师。具体产品页两次 web 打开分别超时/非预期状态，本记录不以失败页面的搜索片段推断其完整布局。

判断/推断：材料叙事可保留感受，但规格和图集需要清楚的边界。将感受与数值放在不同层次，不等于隐藏数据。

采用：暖纸的形态阅读与深绿的复现条件分章，中文短句后紧跟可核查数据。

不采用：不复制器物轮廓、品牌字形、照片或摄影构图；不将模型的自发光材质表述为真实材质透光/光效实验。

首版问题 → 修订决定

1. P1：以 100vw 向外扩展绿底导致真实桌面截图出现横向滚动。v2 将配方章节约束在内容宽度，不用 overflow-x:hidden 遮住错误。

2. P1：只用三张卡，跨变体比较还需记忆。v2 加共同字段的规格矩阵，窄屏转换为纵向字段卡；数据来自模型冻结契约。

3. P1：泛称“同样效果”可能误解为像素一致。v2 紧邻配方列固定渲染条件/合法参数边界/三预设验证范围；明确未证明整个参数域安全。

4. P2：字标占据过多首屏，使具体模型出现偏晚。v2 压缩首屏留白，用产品台面旁的精选规格建立内容密度，不添加更多装饰。

5. P2：首版档案只有4个笼统入口。v2 区分复现源包、三模型、摄影场景、机器可读条件和独立网页复盘，并标实际文件格式与大小。

以上为待完成修订，不冒称已经实资产验收。首版完整文件保存在 before/，首版桌面截图为 review/v1-desktop.jpg。

第二次独立静态复审（资产接入前）

由另一代理只读 app.js / integrate.py / style.css / unit tests，不运行浏览器、不修改模型。发现并修订：

- 首页 Poise 也加载失败时，不应宣称“保留上一张 Poise”。新增实际有效图标志、首图错误播报，以及无成功图时的准确文案。

- 原测试未完整断言 alt / 规格 / 下载链接同步。补齐这些断言及初始失败→下一图失败→恢复成功用例，当前 10 项单元检查通过；它们不是浏览器实测。

- 普通焦橙在深绿上焦点对比约 1.87:1，配方区域改浅橙 #e6b78e（5.77:1）。普通正文强调橙由 #bf451f（4.48:1）加深为 #b73f1c，不靠粗体补救。

- 超宽屏原规则的自动高度/最大高度可能裁掉整灯；改成明确 650px 容器、图像 contain，待 1600/1920 CSS 视口实测。

- 各变体下载增加带型号的可访问名称；接入脚本要求 model-info.config 与相应 JSON 配置完全一致，防止矩阵与模型混版。

以上修改仍需最终资产接入后的浏览器复查，不把静态复审当完成验收。

正式资产接入后的修订与复检

已完成前述修订。三组实际尺寸、8 个输入参数、固定 Cycles 条件均由模型 1.1.0 公开文件接入；几何与 QA 未被网页改写。最终源 ZIP 的 103 项原样保留，并增加独立的 view.html 链接；产品规格图录仍是独立 HTML 阅读设计，不被实时查看器取代。

实际浏览器六档 CSS 视口无横溢；键盘切换同步图、alt、型号、尺寸和下载；禁脚本后全部资料与原生 details 保留；正常图之后的 404 与首图 404 两种情况均有准确状态和恢复路径。根线程另开标签独立复核。独立 3D 入口实际解析三件 GLB 后，明确显示上下文不可用并保留对应离线图。详见 browser-qa.html，不称 GPU / iPhone / 完整屏幕阅读器验证。

最后封包排除真实 404 测试副本、原始占位页面、AX 原始文本、原站截图和预览配置；保留带阶段标签的自有前后截图。源包、模型 manifest 与每件文件的路径核验通过。最终图库返回链接由集成负责人在 studies/005/ 中检查。

复盘：下一轮应延续与改变

- 延续：先写读者任务与数据契约，再画页面。不同模型必须带来不同的信息架构，不能把同一个查看器反复换皮。

- 延续：把固定条件、可变参数和实测结果分栏；“可复现”需要真实命令、版本和门禁，而不只是一个下载按钮。

- 改变：更早在真实首屏看整物，不等大字标排完再发现产品被推下去。超宽容器也需要明确纵横比，不仅处理手机断点。

- 改变：失败设计从首图即开始；不要预设“上一张成功图片”存在。竞态和下载关联应与视觉稿一起验证。

- 保留不足：暖纸和衬线仍延续器物档案气质，创新主要来自规格图录比例系统而非激进配色；下一轮可按对象属性探索更不同的色彩与字形。英雄图的透光层仍薄，页面以正交和接点证据补充，不用文案宣布问题消失。

本轮结束点：模型公开文件同哈希接入、网页最终文件链接与限定范围浏览器复检完成、清洁交付目录冻结。未做公共发布。
