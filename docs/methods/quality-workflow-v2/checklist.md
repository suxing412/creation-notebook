# 造物手记工作法 v2 · 可执行检查清单

这是一张作者执行清单，不是自动放行器。复制 `contract-template.json` 后填入本家族约束；模板保持“未填写，不可放行”。没有报告的项目不打勾。下列步骤不代表本轮重新执行了 005、006 或 F03 测试。

## 一、先决定保证什么

- [ ] 写明几何家族、单位、坐标系、开放／锁定参数、拓扑规则和不适用范围。（P01、P02）
- [ ] 把“输入接受组合”“实际网格通过组合”“人工多视角接受组合”分列。声明连续域未证明。（P01）
- [ ] 固定环境、材料、色彩、灯光、曝光、相机、归一化与渲染条件；决定复现比较是字节、几何还是视觉语言。（P02、I02）

**停止条件**：家族、单位或不变量含糊，不启动宣称可复用的批量生成。

## 二、按本家族写门禁，而非复制白名单

- [ ] 明确 raw 或 evaluated geometry；未支持的修改器、shape key、父子、约束、动画与 driver 不得默许。（G04）
- [ ] 列出对象、连通分量、有限全顶点包络、局部绕序与世界有向体积；开放面另写理由。（G01、G02）
- [ ] 每个构件对声明“必须分离”或具体装配。装配填有限区域、坐标系、端点／嵌深、接触是否必需、整体包络和包容处理。（G01）
- [ ] 拒绝只有 `allowedPairs` 名称清单的契约；在合法接触旁新增穿出棱柱与完全包容岛，要求相应专用字段命中。（G01）
- [ ] 近共面阈值注明尺度、存储精度、角／距离／投影重叠单位；既有命中反例，也有移离控制组。（G03）

**停止条件**：缺少本家族判据、误用旧家族半径／顶点索引、或允许对整对豁免，均不可放行。

## 三、先生成与检查，再花最终渲染预算

- [ ] 保留首版配置、自己的前图与失败报告；正式资产与坏样本目录严格隔离。（D01、D02）
- [ ] 对真实网格跑静态检查；对真实 GLB 字节跑有限坐标、法线、索引、stride、offset、边界、面积与声明一致性检查。（I01）
- [ ] 每个反例记录整体是否拒绝、预期专用字段、专用字段是否命中；其它缺陷碰巧拦住不算专项通过。（G03、G04、I01）
- [ ] 修改检查器后重跑真实样本与反例；旧错误 PASS 不覆盖、不改写成“从未出错”。（G01—G04）

**停止条件**：任何该层必需检查失败，或只存在旧版本报告，不进行该层合格交付。

## 四、报告必须来自这次、这个文件

- [ ] 采用本轮独立报告路径，或先清除目标旧报告。Blender 包装调用必须带 `--python-exit-code 1`。（I03）
- [ ] 同时核对退出码、新生成报告、显式通过、输入 SHA、检查器 SHA 与版本。它们互不替代。（I02、I03）
- [ ] 正式 native 重保存后按正式文件重跑；只对实测相同的文件宣称字节一致。（I02）
- [ ] 重导出若拆点，记录各自顶点数；按世界几何和所需 payload 比对，别把点集距离叫完整拓扑同构。（I02）

作者可将自己已实现的入口按以下**命令骨架**调用；这些不是本页提供的通用 checker：

```sh
blender -b --python-exit-code 1 --python 本家族检查器.py -- --model 本轮模型.blend --report 本轮唯一报告.json
```

随后由包装器验证新报告及身份；**不能**只检查 shell 退出码。实际配方的可复跑命令见各案例文档，不把缺省脚本名当已存在工具。

## 五、把可疑画面变成可回答的问题

- [ ] 形体前后图保持机位、曝光和比较预算；低采样先选轮廓，再按细节需求增加采样。（C02、D01）
- [ ] 对黑点／亮边先固定 ROI，定位对象／面，再用同几何诊断图解释。诊断图不冒充正常外观。（C02）
- [ ] 共用相机与热点配置；实际重开场景检查帧、朝向、纵向 FOV，验证不同视角没有误渲染同一帧。（C01）
- [ ] 图像比例、裁切与内容矩形一致；换比例或摄影必须重新投影校验。（C01）

**停止条件**：不能解释的局部疑点不得被总体 PASS 自动消除；对影响交付的疑点继续调查或明确保留。

## 六、浏览器按失效路径验收

- [ ] 最新图片 decode 成功后原子提交图、标题、热点；坏图不能给旧图贴新标签。（B01）
- [ ] 分离路由与 3D session 的取消；测乱序、GL 失败时待解码路由、取消旧 parse 后重启、主动回离线。（B01）
- [ ] 用原生浏览器测深链、键盘、Back／Forward 与焦点；模拟测试另列，不能代替。（B01）
- [ ] 实看首屏主任务，不只检查横向溢出；窄屏同时检查点击目标与可见标记遮挡。（B02）
- [ ] 无 JS 的正文和锚点可用；禁 GL 保底可用。不得为测试修改受限 GL 设置。（B03）

**停止条件**：阅读被 3D 失败破坏则修复。GPU／真实手机无可用环境则记“未验”，不可借 CPU 或 iframe 冒称通过。

## 七、发布前审的是最终包

- [ ] 列全部文件字节、SHA、用途；检查相对证据链接和返回路径。（D02）
- [ ] 扫描私有路径、原始工作日志、坏二进制、外部图像、密钥与图片元数据。（D02）
- [ ] 体验、源包、报告和内部派生物分开。允许公开的失败结论不删除，坏样本不当正式模型发。（D02）
- [ ] 分层写通过／失败／未验／不适用（附理由），连同版本与最终输入身份冻结。（全部）

**停止条件**：模型质量门禁与发布隐私门禁均有自己的阻断项；某层未验不可改成已通过。只读新证据、只新增方法入口，不改旧冻资产。
