成品之后的参考

Snøhetta 项目库 的作品类型、进度与名称分层，为本轮分类提供方法。研究读取了原站正文和控件标签，不声称实际检验了全部动态效果，也未复制图片。

已落地修订

每轮卡片增加四个入口。三维入口定位同页观察区，网页入口打开完整页面，明确它们是同一实际实现的不同入口，不伪装两份页面。

每卡单列网页设计目标与修订状态，不将模型完成自动视为网页评审完成。

001–004 标为常规双轨；每两轮之后预留三维网页融合类型。F01 仍是任务书，未计为完成作品。

总览弱文字色由 #727369 改为 #62665c，与 #f2eee5 纯纸底计算对比约 5.07:1；不是全页、图片上文字或所有组件的合规证明。

第一张模型图直接加载，其余延迟加载，保留尺寸预留。未测 LCP，不宣称性能提升成绩。

新增可直接阅读的网页评审与逐轮设计说明，报告使用 HTML 转义，所有站内链接采用相对路径。

已检查与未检查

完成本地链接存在性、公开目录隐私扫描和构建检查。总览 v2 的完整浏览器视觉、200% 放大、读屏与真机复查未在本项检查中完成；不将其他观察页的局部测试转用为本页通过。

原始网页评审与任务书保留评审时发现的问题；本页记录后续真正实施的修改，不覆写历史观察。

第二对网页 v2 已集成

003 将三态选择紧邻图像、把环境提示移到图下、用原生折叠区收纳不可用实时工具；004 分离光照与形体检查，增加抵达、门廊、观测章节及标明历史/当前的修复对照。两页静态图片先加载成功再更新状态，失败保留上一张有效图。

这次仅修改网页与说明，不改变模型、渲染、vendor 或原始几何检查。各页设计案例保留具体证据与不足；总览新增区块的浏览器验收由集成端另行记录。

第二融合轮已接入

005源网页已完成所述窄宽、键盘、无脚本与真实404降级等限定验收；总览新增卡片与返回路径仍需集成后检查。5常规、2融合的分类不提前计入F03。

新增第六常规轮折页，独立网页与GLB观察器分别进入index.html与view.html。三种比例的面数不同，卡片明确显示Folio基准；模型review与网页web-review独立保留。已收录常规六轮、融合两轮，不提前将F03列为完成。

将005暮灯与006折页配对为第三融合轮，用共享真实桌面、三个章节与留白组织阅读；独立复盘、QA和源包入口保留。计数为6常规/3融合，不新增虚构007。F03源包已完成根复查与独立限定审查；GPU、动态闪烁和真实手机边界保持。总览接入不覆盖原模型或审查记录。
