# 总览逐版验收

## 每一版交付都执行
1. 新作品冻结包通过原件身份检查后才加入manifest；常规/融合/配方/方法分开计数，最新常规入口自动更新。
2. 原始资产不能因总览改版改变。核对新增全集及旧条目的逐文件SHA；目录可保留源包内无损原件映射。
3. 更新publication-ledger.json仅依据精确提交、部署终态和实际公开访问。归档不是上线，CI成功不是可访问；无证据为公开待核验。
4. 重建两次零差异；所有图像、作品、复盘、源文件、锚点在本站前缀内可达，不能把仓库根路径当网站根。
5. 默认不加载Three/GLB。仅显式开启3D时载入本地Three；展台、按钮、选择详情必须来自同一catalog，禁止漏项和重复ID。
6. 比较常规/融合/方法数量、最新入口和每卡标题；检查无JS全部可读、320/390 CSS不横溢、键盘Tab/Enter能进入作品/展开证据/开关空间。
7. 验证GL失败、模块/目录失败、开启后快速关闭、重复开启、页面离开/返回的清理；首屏列表不被失败吞没。
8. 有真实GPU时再验选择、镜头与动态闪烁/性能；没有则明确未验。CSS窄屏不等于iPhone。
9. 部署后再次实际打开总览和新作品、至少一个复盘/下载入口，记录精确版本与限制。不能提前把候选包称为公开交付。

## 规模边界
空间模块最多60条目，超过必须重新设计分区/分页并验证，不能静默截断。图片懒加载，展台不自动载入所有模型。当前总览是目录，不计入2+1作品轮。

## 每次扩容的明确检查
新增编号须有可辨认目录符号；无适配时不得把通用方块当作已完成辨识设计。末行不足列数时居中，检查全景/聚焦投影及拾取；首屏抽象示意不是逐件布局图。分类名保留时仍检查用户能否从首屏解释理解模型＋独立网页与三维章节导航的区别。

## 用户纠正后的类别契约
展示名称为“模型与介绍页”和“3D空间设计”。F01–F04保留历史实验、公开已核验，独立设计状态为按新要求待重做；不得把已公开等同于满足新设计要求。当前新空间设计成品为0。新成品须明确评审后更新schema/测试，不允许新增kind=fusion卡片自动升格。3D总览只是目录索引，不是整页三维空间设计范例。

## 新空间原型接入
space-design必须独立于fusion历史实验。分别检查0已验收/原型数/历史待重做/公开数，原型不因部署成功升格。总览主入口可突出最新原型，仍保最近模型；目录需独立原型区并保留待验收标识。新类别若缺目录模块支持应失败而非静默漏展台。静态主入口、无JS、无GL、源分卷和原章节返回均须复查。
