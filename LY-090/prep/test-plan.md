## 1. 孔开放性检查（scripts/hole_check.py）

配置写法照 `tests/hole-check-config.json`：图层按顺序组合，后写者覆盖同名节点，`replaces` 是显式替换。每个孔检查两件事：
- **孔内**：r = 0、0.25R、0.5R、0.75R 各 32 方位，再加 R − tolIn（0.01 m），共 129 条射线。从 topY+0.3 一直打到孔底 bottomY，必须**一条都不打中**。
- **孔外**：R + tolOut（0.01）、R+0.1、R+0.5 三圈各 32 方位，共 96 条射线。每条的**最高面**都必须是 topY ± 0.011。

正例（必须 PASS）
- P1：合成输出替换宿主节点以后，每个被接纳的孔都 PASS。prep 用 S1 预演过：井孔 0 堵、0 失托。
- P2：v1 flow=B 口径（7 条 route_* 已 retire，加 flowB-routes）。prep 预演 S7 已 PASS。
- P3：app 口径（四片原子地面 + market-main + N2）。用 S1 的图层顺序跑。
- P4：把合成输出的图层顺序打乱，跑 N!（N ≤ 4）个全排列，或随机 24 种，结果必须相同。合成器只输出一个替换件，所以排列只影响装载顺序，不应影响结果。

负例（必须 FAIL；如果 PASS，说明检查器本身坏了，判阻断）
- N1 当前 main 没有孔：129/129 被堵（S0）。
- N2 封回：开孔以后，又叠一个从旧基底派生的整片补丁（S2/S3）。
- N3 盖孔：一块铺装在孔上面（S5 夹具：route_rearS 平移 z −10 m）。
- N4 二次平移：开孔地面再平移 +0.2 m（S6，96/96 失托）。
- N5 双层地面：旧 sample_ground 不排除，同时加载开孔件。用 S2 的 onlyNodes 夹具，但不写 replaces。
- N6 孔过大：外圈 R + tolOut 处必须有地面。夹具做法：把孔清单里的 R 改小 0.05，预期外圈失托。
- N7 多出来的孔：在宿主上取 100 个不在任何孔清单内的随机点，最高面必须在 topY，不能是空洞。
- N8 089 封孔：把 LY-089 的每片差异片（terrain-diff-*.glb）与合成输出同时加载，对每个已登记孔跑孔内 129 条射线，任何一条打中差异片即 FAIL。prep 夹具：S5 的做法（把一块板平移到孔上）已证明检查器能抓到覆盖。
- N9 删三角过切：把厕孔（若获准）做成「删除与孔矩形相交的 south 整三角」的错误版本。孔外 R+tolOut 一圈必须出现失托；LY-045 负例 N8 测到 206/744 个围圈底面采样失托。正确做法是多边形差集后重新三角化，孔外失托 = 0。
- N10 孔清单计数一致：同一个孔，前置席位和本席位对宿主三角的计数必须一致。prep 现状：厕孔下 south 三角，本席位精确分离轴法 4 个（1 m 内 14 个，out/privy-rect-tris.txt），LY-045 prep 记 8 / 16。不一致就停，先对口径，不合成。

容差：tolIn = tolOut = 0.01 m；顶面 ±0.011 m（含 route 0.21 和 south 微起伏 0.2014）；坐标约 2000 m 处 float32 精度约 1.2e-4 m，所以比较容差不能小于 2e-4 m。

## 2. 顺序与单一输出

- O1 单一写入：在 assembly.json 里，每个宿主节点（文件 + 节点名）对应的替换件数量必须 = 1。任何一个宿主节点被 2 个以上席位声明要写入，判阻断，交 LY-006。
- O2 从基底一次减：替换件 = 基底 − ⋃孔。验证：替换件的顶点里，除了各个孔圈，其余顶点集合与基底完全一致（容差 2e-4 m）；面积差 = Σ 孔面积 ± 1%。prep 观察：井孔 LY-025 实测体积差 0.2181 m³，理论 0.2187。
- O3 孔两两不重叠：把孔外扩 0.3 m 净距以后，同一宿主上两两求交，交面积必须 = 0；跨宿主的孔落在拼缝 ±0.5 m 内的，单独列出。prep 现状（out/datum-pairs.json）：有（候选）世界坐标的孔 2 个，井在 market-main:sample_ground，厕候选在 ground-south，相距 1,186.779 m，共用宿主 0 个，同宿主孔对 0 对。正例要用两个以上同宿主的孔，没有就造夹具（同一宿主上两个相距 0.5 m 的假孔，预期 PASS；相距 0.2 m，预期 FAIL），只用来证明检查器有效，不交付。
- O7 基准一致：每个孔清单都必须写明宿主板顶高程（LY-005）。水道按板顶四个候选高程测出的板带内面积是：0.00 → 7.35 m²；0.60 或 0.76 → 6.54 m² 加 0.81 m² 净口；1.80 → 1.44 m² 外壁圈加 0.81 m² 净口（out/datum-pairs.json）。LY-086 交来的切孔多边形面积必须与所选基准下的重测值相差不超过 ±2%（0.05 m 栅格误差）；没写基准的孔清单直接拒收。
- O8 板下埋件：几何整列都在板底以下的面积大于 0 的（水道在基准 1.80 时为 5.91 m²），在 qa 里标「埋于空心板下，城里无土体」。本席位不补土体，只拒绝把它报成「已埋设」。
- O4 叠层孔：孔足迹内所有可走顶面（route_*、flowB_*、floor、boundary）都要列出来，并且每一层都在切孔清单里。用 ground_stack.py 的 `tops()` 逐孔跑；漏切任何一层判 FAIL。
- O5 LOD 一致：孔多边形取各档井筒、坑壁外轮廓的最大包络。井 A：LOD0 填实 1.10 m²，LOD1 1.08 m²，外半径都是 0.59 m。
- O6 外接多边形：井孔 r ≥ 0.59131 m（48 边，弦高 1.263 mm），否则井筒和地坪的交体要逐对归类，不能整体豁免。

## 3. 交体与接触（Blender 布尔，`D:/Blender/blender.exe -b --factory-startup --python-exit-code 1 -P`）

- C1 每个孔的「孔下内容物」（井筒、坑壁）与替换宿主求精确布尔交体积，必须 ≤ 1e-6 m³，或者逐对归类为局部嵌接。prep 现状：内接 48 边孔对井筒 = 2.655e-6 m³（LY-025 实测）；外接孔应接近 0。
- C2 旧宿主（基底）与孔下内容物的交体积必须 > 0。这是负对照：sample_ground 对井筒为 0.09122 m³。
- C3 通孔与凹槽分类：宿主板厚 0.20 m（stitched 0.21）。深度 ≥ 板厚的是通孔，孔下必须有前置席位的坑壁、坑底，否则判「孔下透空」，不放行。深度 < 板厚的是凹槽，槽底余厚 < 0.03 m 的标近共面风险。水道按顶 0.2 对齐时余 0.02 m，会被标出。
