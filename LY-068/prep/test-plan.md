## T0 输入不变（回归）

1. 先重跑 `prep/tools/measure_b_ports.py`。B 三档必须同时满足：
   - deck z 3.500 ± 0.001
   - 端口三带宽 2.10 / 2.12 / 2.10 ± 0.01
   - 柱脚数 12
   - 带内净空最小 2.66 ± 0.01
2. 安装、撤回前后，B 与 access-A 的 GLB SHA 不变。
3. 负例：改用任何其他 B 字节，T0 必须报失败。

## T1 端口高度一致（本项验收第一条）

- **正例**：新平台面在端口 x = 4.50 内侧 0.3 m 范围内（以 LY-006 端口 ID 指定的端为准），按 0.05 m 网格下射，全部命中平台面 z。并且 |z_platform − 3.500| ≤ **0.005 m**。B 端缘 x = 4.49 与平台 x = 4.51 处的高差 ≤ 0.005 m。
- **正例**：沿三带中线（y = −2.40, 0.00, +2.40）各取一条剖面，从 B 中心 x = 0 走到平台另一端，每 0.02 m 采一个点。要求没有 > 0.005 m 的跳变，也没有缺面（gap）。
- **负例（必须失败）**：
  - access-A LOD0 平移到 x = 4.5。现有脚本 `dock-access-A-to-gallery-B-plus-x` 给出 +0.500 跳变，检查器必须判红。
  - 把新平台人为抬高 0.02 m，检查器也必须判红。
- **端口间隙**：平台缘与 B 楼面端缘之间水平间隙 ≤ 0.01 m，且不得重叠进入 B 楼面板体（见 T4）。

## T2 宽度与净空

- **正例**：平台端口净开口覆盖 y −3.45..3.45（≥ 6.90 m）。如果设计只服务中带，必须在 assembly.json 声明 `servedLanes`，并对未服务的带给出「不通」结论，不能默认为通。
- 每条服务带在平台全长上做上射，要求净空 ≥ **2.0 m**，与 B 带内基准 2.66 一起记录。
- 梯段净宽 ≥ 设计值。从踏面上 0.9 m 处横向射线，测扶手之间的距离。
- **压力负例**：宽 2.2 m 的身体包络。在 B 带内会碰柱（已知），在梯段上必须报超出梯面，不能静默通过。

## T3 梯级与 LOD/碰撞契约（本项验收第三条）

- 从中线剖面提取每级踢高和踏深：
  - 近景档与碰撞件：所有踢高相等，偏差 ≤ 0.003 m，踢高 × 级数 = 3.500 ± 0.005。
  - 踏深 ≥ 设计值。实测值和设计值都写进 qa。
- 级数表要逐档列出：LOD0 / LOD1 / LOD2 / collision 各自的级数和踢高。允许展示 LOD2 减级，但碰撞件必须与近景级数一致。
- **负例**：用 LOD2 的剖面跑「通行」判定，检查器必须拒绝，因为展示 LOD 不作通行依据。
- 碰撞件与展示件分文件、分节点，并有 extras 标记 `usage: collision-candidate, not engine certified`。

## T4 支持与交体

- **足下支持**：平台面 0.1 m 网格下射，100% 命中。所有踏面 0.05 m 网格同样 100% 命中。
- **悬空**：平台柱、梯梁的底面在局部地坪 z0（LY-005 冻结值；未冻结前用 B z0 = 0.000，并标明是局部演示地面）上，误差 ±0.005 m。不得埋入 > 0.005 m；access-A 的 −0.2 m 埋入不得照搬。
- **B 柱脚避让**：新件与 B 端部柱和柱脚（x 4.25..4.75；y ±1.2、±3.6；z 0..3.5）的正体积交体 = 0。只允许分类为「局部接面」的接触，而且要逐对列出。
- **全对交体**：新件内部构件对、新件与 B 各构件对分三类报告：合法局部接面、正体积侵入、完全包含。正体积侵入的容差是 0 m³，超过 1e-6 m³ 判红。只用表面 BVH 时要写明这一点，不能说已穷尽实体碰撞。
- **檐口**：平台栏杆最高点 < B 檐下 z 6.44 − 0.10。

## T5 完整路线可重现（本项验收第二条）

- 路线：局部地坪 → 梯脚 → 各踏面 → 平台 → B 端口 → B 楼面中心。按离散采样输出 csv，记录 x、y、z、命中构件和净空。
- 身体包络：宽 0.6 m、深 0.4 m、高 1.8 m 的盒子，按 0.05 m 步扫掠。同时报告是否离开支持面、是否撞物。写明「离散扫掠，非连续人体/车辆/强度认证」。
- 负例：把梯段换成 access-A 的梯段，路线在端口处必须断开。

## T6 三档安装参数与撤回

- assembly.json 要写明：B 端口 ID（来自 LY-006）、平台端口 ID、局部变换（只平移和绕 z 旋转，不缩放）、三档对应关系、互斥规则（access-A 与 access-B 不得同时装在 B 上；A 端不装 access-B）。
- 安装后回读，世界矩阵与 assembly.json 一致，误差 ≤ 1e-6。撤回后，B 节点、几何、材质、矩阵的 SHA 和数值与安装前逐项相等。
- 叠载负例：同时装 access-A 和 access-B，检查器必须判红。

## T7 公共底线

- 单个 GLB ≤ 15,000,000 B。LOD0 不得复制改名成 LOD1/LOD2，检查方式是三档三角数和 SHA 互不相同。
- UV、法线、退化三角 = 0，有限值检查。纹理内嵌，米制，原点写明。
- `lab/tools/build_assets.py --check` 只由 LY-100 在合并队列中跑。本席位不跑。
