## 2. 正例（装上踏步之后，每个开口都要单独通过；三档分别跑）

装法：把交付的踏步 GLB 与店前线同场导入；母版检查时再加上分块（它自带地坪和路带）。

- P1 足底分层：从路带边 y=±1.8 → 开口中线 → 柜后线 ±(5+1.60) → 横移到铺中线。每 0.05 m 一个足点，足底 0.24×0.24，打 5 根射线。
  - 任何一次上升 ≤ 0.150 m（建议设计成 2×0.110；容差 ±0.005）。出现 0.22 的单次跳升，或者单级 > 0.15，都判不通过。
  - 每一级踏面沿走向连续有支承：至少 0.28 m 长度内 5 根射线全中，足底高差 ≤ 0.005。
  - 起步外端（踏步最外 0.05 m）下方要命中地坪：母版里是 `C_market_ground_well_A` 顶面 0.000，单独检查时是 LY-005 冻结的地面面。踏步底面和地坪之间的间隙 ≤ 0.002，侵入 ≤ 0.001。
  - 店内地板：在开口内 0.30 m 处命中台基顶 0.220±0.001。
- P2 身体体积：0.50 宽 × 0.30 深 × 1.75 高，离足 0.02，每 0.10 m 检一次。表面 BVH 交叠为 0，且没有三角完全落在盒内。在踏步上转身的位置要加检一次方向互换的盒子。
- P3 柜后不回退：只在 LOD0/LOD1 上跑。柜后线 1.60 m 横移全程身体通过；12 个开口的净宽和 3.1 节表格一致（1.10 / 2.40 / 2.58，±0.005）；三个源网格的指纹和第 0 节完全相同。
- P4 接触分类（踏步对其他物体逐对列出）：
  - 踏步立面对台基前沿立面：合法共面接面，间隙 ≤ 0.002，正体积侵入为 0（数值容差 1e-6 m³）。
  - 踏步底面对地坪：合法共面接面。
  - 踏步对前檐柱、柜台、墙、棚、井、路带：不允许接触，最小距离 ≥ 0.02。路带归 LY-022，不能盖上去：踏步外缘必须在 |y| > 2.00。
  - 只做了表面 BVH 的，报告里要写明。完全包含要另外用顶点落盒检查。
- P5 头顶净空：踏步每一级上方，到檐瓦或梁的净距 ≥ 1.75 + 0.02（现在实测檐底 ≥ 2.8）。
- P6 三档：LOD0、LOD1、LOD2 三个文件各自跑 P1、P2、P4。LOD2 没有柜台，P3 不适用，要在报告里注明。不能把 LOD0 改个名就当另外两档；如果简单盒体三档确实等价，要写清楚各档的差别（倒角、UV、底面剔除）以及为什么这样处理。
- P7 文件底线：每个 GLB ≤ 15,000,000 字节；UV、法线齐全，没有 NaN，没有退化三角；米制；原点按 LY-005 契约；材质用 LY-007 的语义名。最后由 LY-008 检查器和 `lab/tools/build_assets.py --check`（LY-100 合并前跑）把关。

## 3. 负例（每条都必须判不通过，证明检查会失败）

- N1 不装踏步（也就是现状）：12 个开口每个都报出 +0.220 的单次跳升。现有证据：out/entry-*-vground.json。
- N2 踏步沿进深方向往台基里推 0.05：P4 报正体积侵入。
- N3 踏步整体抬高 0.03：P1 报起步外端悬空或间隙超限。
- N4 去掉地面（库文件不加虚拟地面）：外段足点悬空。现有证据：out/NEG-entry-LOD0-noground-behind1.40.json，62 个足点悬空。
- N5 柜后线改成 1.40：身体盒和柜台背面交叠。现有证据：同一个文件。
- N6 只设一级 0.22：P1 报上升超过 0.15。
- N7 踏步往外伸进路带（外缘 |y| ≤ 2.0）：P4 报和路带接触或重叠。
- N8 新旧叠载：同一个场景里同时载入旧五店三摊的 `*_frontstep`（market-cluster）和本踏步件，安装检查必须拒绝。

## 5. 报告必须写明的限制

做的是离散足点和盒体检查，不是连续人体仿真，也不做结构强度和现代无障碍规范认证。所有图都是 CPU 渲染，没有做浏览器或 GPU 测试。踏步形制和级高属于 C，没有约 180 年洛阳的原文或图版支持。“模型能读取 / 局部通行通过 / 已入城 / 真实结构安全 / 历史复原成立”分开写，不能互相顶替。
