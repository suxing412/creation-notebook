# LY-003｜配准南北宫与东北约束

席位类型：考据/契约。基线：`creation-notebook-lab` 提交 `bce3211f818ee5a8bef1773539da70695ba37b17`，只读，全部用 `git show` 读提交字节。前置：LY-001（城景快照）、LY-002（证据与禁用表）。

## 结论

**南宫、北宫、两宫复道、永安宫、宫墙水道都不能落位。** 这些对象在任何坐标系里都没有能和项目坐标对上的共同控制点（0 个）。平移至少要 1 个点，刚体或相似变换至少要 2 个，仿射至少要 3 个；要做独立校核还得各多 1 个。所以一个变换也解不出来，本包也没有算任何“低误差”的宫墙坐标。

按任务补充条款，本包交的是控制点缺项清单和不可落位结论，另外给出项目现有坐标框架的自检、宫区悬置区（禁用区域），以及东北仓储、东北接路要满足的条件。

## 主要发现

1. **项目坐标只是“示意米”。** `luoyang-local-schematic-v01` 是把高崇文 2023 年图 1（徐龙国制图）按 500 米/49 像素数字化得到的，没有地理原点，也没有真北方向。城景直接使用这套坐标（city-data.mjs 的 coordinateFrame 与它相同）。这一步可以完全重算，但它不说明图和地面是什么关系。
2. **示意城垣和实测长度对不上，几组实测数字之间也对不上。** 东垣残长 3895 米（两组来源一致），比示意图上东边的全长 3668.6 米还长 6.2%。这里的全长已经算进了推定的南段。北垣有三种说法：2523、2820、3700 米，折成比例分别是 0.913、1.020、1.338。西垣也有三种：3500、3510、4290 米。按北垣数字做等比缩放：T1-A 和 T1-B 缩放后东边还是比残长短，和东垣矛盾；T1-C 不矛盾，但它要把整张图放大 34%。所以不能反算出唯一的比例。现行框架 T0 保持不变。
3. **新发现的北宫墙只有文字，没有坐标。** 2023 年度河南十大考古新发现的巡礼条目说，东汉北宫的东墙、南墙利用台地边缘冲沟内侧修筑，范围和魏晋、北魏宫城“大致相同，只是……略有摆动”（Q04、Q05）。条目开头本身用了“或与……有关”的保留说法（Q03），新闻转述时把这层保留去掉了（Q09）。年度综述又说宫城东墙外最下层有不晚于东汉的道路，在冲沟内，宽约 23 米，道路西侧有不晚于东汉的夯土墙（Q06、Q07）。但后期宫城南墙只有一道，始建年代晚于东汉（Q08），这和“东汉南墙”要放在一起读。上面这些位置都只是相对北魏宫墙说的，项目坐标里没有北魏宫墙。原机构页面（News_ID=2283、2810）**未能访问**。
4. **旧 B 北宫和报道的“范围大致相同”在尺寸上冲突。** 旧 B 北宫东西宽约 1209 米，是后期宫城东西宽 660 米（三手资料 Q15/Q17）的 1.83 倍，多出 550 米。南北长 1398 米，和北魏宫城南北长 1398 米相差不到 1 米。这可能是巧合，也可能说明示意图的北宫本来就借用了后期实测数字。本包读不到制图说明，这一点**待核**，不作结论。
5. **南宫的位置还没有勘查清楚**（Q01）。示意包络只是一种说法。
6. **宫墙水道**：千秋门下有不晚于汉代的砖券水道，内宽 1.2 米（Q10、Q11）；宫城西南角下有汉晋时期的大型河渠（Q12）。这两处都只有文字，分期跨汉、晋，约 180 年是否在用不知道。宫城东侧的仓窖区和砌砖水渠属北魏（Q13），不能当作东汉太仓。
7. **东北。** 现在已按章入城的仓储组（granary-city-LOD0.glb，SHA `5937211c…`）凸包范围是 x 2249.7–2321.7、y 3647.5–3699.5。它离 HZ-N 外缘 342.4 米，离永安宫 400 米圈外缘 168.6 米，离 `road_east_north_link_B` 80 米带外缘 369.7 米，离示意城垣 65.6 米，不在任何悬置区内。这只说明它和旧研究示意图不冲突，**不证明它在宫外**，因为 e3、e4 没有数字。东北 C 试放筛查区约 56.2 公顷，规则写在 `ne-checks.json`。**C_NE_APPROACH_LOCAL 在 bce3211 中没有找到**，所以约 196 米那条短路的端点没法核对。

## 证据分类

- **原始考古／原文**：城垣残长（二手转引 1973）；2023 年北宫墙段、冲沟道路（只有转载文字）；千秋门水道、西南角河渠（只有新闻或成果短文）；南宫、北宫存在（原文，见 LY-002 E-P01）。
- **异地异期类比**：北魏宫城尺寸 1400（1398）×660 米，只作“范围大致相同”的对照，不替代东汉北宫；阊阖门属曹魏，禁用。
- **C 工程设计**：悬置区外扩值（沿用仓库筛查值）、东北筛查区、候选比例变换。
- **未知**：e3（图与地面）、e4（墙线摆动量）、南宫位置、太仓和武库的东汉位置、千秋门水道约 180 年是否在用。

## 五件事的边界

本包只回答“能不能在项目坐标里落位”。它不证明任何模型“能读取”“局部通行通过”“已入城”“真实结构安全”或“历史复原成立”。表里说仓储组“已入城”，沿用的是 LY-001 的现状记录，不是本包的结论。

## 不改什么

没有改仓库里的任何文件，没有运行 git 写操作，也没有运行 `build_assets.py`。生成凸包时，GLB 的提交字节临时写进 `LY-003/qa/`，读完马上删掉。外部网页和 PDF 都有版权，不随包分发，只登记 SHA256。本席位不涉及 .blend 或源 ZIP。

## 局限

- 8 份原始图版一份也没有拿到（见 `control-points.json` 的 missing_plates），其中考古 1973(4)、考古学报 1998(3)、考古 1988(9)、考古 2003(7) 都是期刊扫描件。
- 北魏宫城尺寸只来自百科类三手页面，没有出处。城垣数字也是二手、三手资料，量法和是否算进金墉城都没有说明。
- 外扩值是工程筛查值，不是历史误差范围，所以悬置区外的位置照样不能称为“宫外”。
- 东北仓储的“东北隅”本身也只是研究推定（LY-002 E-S01）。
