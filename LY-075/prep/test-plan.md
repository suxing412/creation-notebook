## 2. 正例：可达性

参数网格：H ∈ {1.75, 2.0, 2.3}，r ∈ {0, 0.25, 0.30, 0.45}，s ∈ {0.16, 0.20}，共 24 组。G 冻结后，要把这组参数换成 LY-010 的正式包络，至少包括人体和最宽货物两档。

| ID | 检查 | 期望 |
|---|---|---|
| P1 | 分别从 N、E、S、W 四个台阶种子出发，看 `per_seed[side]` | 每个种子都包含 9 个室和回廊。比回廊大的 1–2 格碎片（A-LOD2 角柱缝）只在报告里列出，不判失败 |
| P2 | 16 道门在局部子图（房 a ∪ 门道 ∪ 房 b）里逐道检查 | 全部 pass，不允许靠绕行来计数 |
| P3 | 可达的身体中心格 | 地坪是有限值，净空 ≥ H，地坪 ≤ 台面 + 0.30，到无护栏边（\|ΔZ\| > 0.5）和障碍物的距离都 > r。rooms_reach.py 内置这条规则 |
| P4 | LY-074 交付后重跑 | 见下 |

P4 的做法：
1. 把合成地面（void→y=0）换成 LY-074 交付的真实地面 GLB，与明堂一起导入后重新打射线。
2. 种子只放在 LY-006 端口 `mingtang:side-*:ground` 的 local 坐标处，按端口容差（位置 0.005 m、标高 0.002 m）核对端口到阶脚的高差。
3. 重跑 P1–P3。报告要写明种子来自哪个端口、端口版本号和地面 GLB 的 SHA。

## 4. 逐项结果表（验收格式，`make_item_table.py`）

每份 GLB 出一张表 `out/items-{A,B}{0,1,2}.md`，共 60 行：9 个室、16 道门洞、16 道门槛、16 根立柱的侧面，再加 3 个固定的未知项。列为：

`项 | 结果（可达/受阻/未知） | 依据（参数组数、种子、宽/门头/净空） | 绑定 SHA`

填写规则：
- 门槛行固定写：「模型无门槛几何（0.000 m），门道平地可达；历史门槛形态未知」。
- 柱侧行固定写：「不构成独立通道：位于墙交点，九室/回廊无独立柱」，并附 T8 的距离。
- 「重屋」上层、门扇开闭、台缘跌落安全三项固定写「未知（未建模）」，既不写可达，也不写受阻。
- 任何「受阻」都不能靠删柱、开门或加梯消除，只能保留并写明原因。
- 正式交付时，种子必须换成 P4 的真实端口，表头那句「synthetic ground」也要删掉。
