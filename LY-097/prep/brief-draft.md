## 4 证据与未知

- 本席位的所有数字都是**工程运行测量**，不是史料。没有引用任何考古、原文或异地异期类比，也不涉及北魏洛阳、西汉长安或四川画像砖。

**通过的项**（dgpu-b 对 dgpu-a 的判定见 `qa/verdict-dgpu-b-vs-a.json`：R1–R11 全部 PASS，只有真机一项是 UNTESTED）：

**缺口与观察**：

1. **没有真机环境**：物理手机 0 台、平板 0 台，没有 Safari 和 Firefox。手机只做了 Chrome 仿真（390×844，DPR 3，触屏）：先停在 poster、不请求 GLB；点开以后 `ready`，52 次绘制。仿真下画布从 y=690 开始，大部分在 844 高的首屏以下。R11 真机按规定记 UNTESTED，是否阻断等 LY-010。
2. **集显帧余量小**：重载视图（66 节点、全城档、108 次绘制、634,440 个三角形，画布 1110×681）在集显上的 GPU 同步帧是 p50 13.3 ms、p95 13.8 ms，距 16.7 ms 只剩约 3 ms；独显是 p50 1.3 ms、p95 1.5 ms。更大的窗口、DPR 2 屏幕和后续批次增加的几何体，都可能让集显掉到 60 Hz 以下，**这一点没有测过**。
3. **视觉门只看比例会漏检**：N04（wall-05 被换成 wall-00 的字节）在全城档只改了 216 个像素，比例 0.029%，低于 0.002 的比例阈值。同设备噪声底是 0 像素（45 张里 44 张字节完全相同），所以判定器加了绝对阈值 `--tol-abs 50`。另外，换在住宅档首屏视野外的墙，截图字节完全不变，也就是说：**不在任何截图视野里的改动，视觉回归抓不到**，每批都必须给改动区域补机位。
4. **跨设备不可比**：独显对集显最多有 1.46% 的像素不同。跨设备的判定里 R9 和 R10 都是 FAIL，所以必须同类设备对同类设备比较。
5. **贴图在城景里看不到**：渲染器只保留 position 和 normal，颜色走 `pigmentFor`。但有 4 个 GLB 内嵌 9+9+9+3 张贴图，共 3,498,392 字节：广阳门门体、仓储、雍门近档、雍门地坪。这些贴图照样下载、解码，然后丢弃，约占全城模型量 13,466,348 字节的 26%。贴图正确与否只能到资产详情页的 viewer 去验，城景验不了。这一条交 LY-096 / LY-007 参考。
6. **有一章没有 UI 入口**：清单里的 `yong-gate`「雍门与通口」章有机位，但 `index.html` 没有对应的按钮，只能用 `?chapter=yong-gate` 进入（14 次绘制 / 16,772 个三角形）。交 LY-098 / LY-100 判断是有意隐藏还是遗漏。
7. **v1 归档入口是连续渲染**：`?mode=west` 跳转到 v1 后，WebGL 绘制调用累计到 514,689 次，说明它在持续跑渲染循环；当前入口是按需渲染。v1 页面没有 `#stage` 状态，所以只记录请求和截图。
8. **资源计数器的局限**：GPU 显存读的是 Windows 计数器 `GPU Process Memory(pid_*)\Dedicated Usage`，统计的是整个浏览器 GPU 进程（独显 121–212 MB，集显 190–256 MB），不是单页。集显主要用共享内存，这次没采 Shared Usage。JS 堆峰值约 49–51 MB，但早一轮运行曾出现 77.8 MB 和 84 MB 的单次峰值，GC 抖动大。
9. **headless 帧间隔不能当 FPS**：页面按需渲染；镜头飞行时的帧间隔约 4.2 ms（独显）和 9–12 ms（集显），不受 vsync 限制。键盘环绕的约 31 ms 由发键节奏决定。
10. **测试工具教训，不是页面缺陷**：第一次运行时 `Network.enable({maxTotalBufferSize:0})` 导致手机仿真步骤报 `ERR_NO_BUFFER_SPACE`，看起来像动态 import 失败。单独复跑后确认是测试工具造成的，已经去掉该参数。以后重放出现同类报错，要先排除测试工具本身的问题，再报页面问题。

测量脚本都在 `prep/source/`：`run_runtime.mjs`（运行场景）、`probe_openings.mjs`（开孔）、`diff_shots.py`（截图差分）、`check_run.py`（判定）、`selftest_checker.py`（判定器自检，8/8 符合预期）、`summarize.py`、`build_inputs.py`、`audit_textures_pigment.py`（GLB 贴图与颜色复算，输出 `qa/texture-pigment-audit.json`）。
