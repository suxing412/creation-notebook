## 框架约定（全部测试共用）
- 采用 LY-006 的 `local:biyong`：原点在礼堂 A 的本地原点，也就是台面顶中心，y=0。坐标轴为 +X 东、+Y 上、-Z 北（glTF）。
- N_hall = I。
- N_encl,k = T(0,-1.2,0)·R_y(k·90°)，k = 0..3。
- 试配组原点 O 位于 local:biyong 的 (0,-1.2,0)。比对试配时，统一用「试配坐标 − O_world + (0,-1.2,0)」换算。

## T0 输入身份
- 正例：6 个 GLB 和试配分块的 SHA256 都等于绑定值，Blender 导入不报错。礼堂有 3 个节点，名为 earth/timber/tile；围护有 1 个节点。所有节点的 matrix_world 都是单位矩阵，即 GLB 内部没有烘进平移。
- 负例：任何一个 SHA 不同，判失败。GLB 内部出现非单位矩阵的节点，判失败（违反 R4）。

## T1 本地框架与尺度（每档都测）
- 礼堂：
  - 台面顶 y=0.000，台底和踏步脚 y=-1.200。
  - 台缘 |r|=18.000，踏步外缘 |r|=20.400，踏步侧向 ±2.000。
  - 6 级，每级 riser 0.200、tread 0.400。
  - 容差 2 mm（E3）。
  - 三档的 earth 节点逐点一致（偏差 0），bbox 都是 (-20.4,-1.2,-20.4)–(20.4,8.76,20.4)。
- 围护：
  - 底 y=0，顶 y=2.000。
  - 中心线 |坐标|=68.000。
  - 底厚 0.700，顶厚 0.500。
  - 臂端位于 4.000。
  - 容差：LOD1/LOD2 为 2 mm；LOD0 截面允许夯土起伏 ≤15 mm（实测 14.6 mm）。
- 负例：把任一 GLB 缩放 1.001 后再测，必须判失败（R2）。这是为了确认检查脚本对尺度变化不是盲的。

## T1b 继承缺陷基线（本项不修，只要求不变）
- 正例：焊接容差 1e-5 m 下，非流形边计数如下（开放边全部为 0）。安装前后读回的计数都必须与此相同。

- 负例：计数变化，判失败，因为这说明几何被改动了。输出里出现「整体无缺陷」「完全闭合」之类的措辞，也判失败。

## T2 局部变换（核心检查）
- 正例：
  - 所有 N 满足：scale 为 1，det>0，只绕 +Y 旋转（R1–R3）。
  - 公开 LOD0 礼堂套上 N_hall 后，与换算到 local:biyong 的试配礼堂比对，Hausdorff ≤ 0.25 mm（实测 0.119 mm）。
  - L-LOD1 按 4 个 N_encl,k 放置后，与换算后的试配 A-v2 比对，双向 Hausdorff ≤ 0.25 mm（实测 0.133 mm），三角形数为 9,488。
- 负例（以下每一项都必须判失败）：
  - N1 同原点直叠：礼堂和围护都用单位矩阵，礼堂脚 − 围护底 = −1.200 m。
  - N2 重复施加：同时用了「组框架 +1.2」和「围护 −1.2」两种写法，或者预合成 GLB 已经烘了偏移、节点 N 又再施加一次。结果相对高差为 ±1.200 m（礼堂脚悬空 1.2 m，或围护沉 2.4 m）。
  - N3 只放 1 个 L：试配与组合之间的 Hausdorff 为 154 m，判为「围护不完整」。
  - N4 四个实例旋转方向错误（例如四个都是 0°）：几何在同一处重叠，按完全包含判失败。
- **不能用碰撞代替这个检查**：单位矩阵错叠时，BVH 三角形交叠数是 0（已实测），所以 T2 必须检查高程端口。

## T3 台基 / 围护接口
- 冻结端口：`biyong:hall-enclosure:ground` v1（kind=ground，producer/steward 为 LY-071，consumers 为 LY-072、LY-073，容差 position 0.005、elevation 0.002）。
- 交付时填写的值：

  - nodeMatrixColumnMajor 写 5 个 N。
  - world 保持 null，因为未准入。
  - measuredFrom 写实际读回的脚本和输入 SHA。
- 子点只放在 assembly.json 的 `subPoints` 里，作为端口附注；它们不是新的端口 ID。新增端口 ID 需要 LY-006 v2。子点包括：
  - 踏步脚四处：(±20.4,-1.2,0)、(0,-1.2,±20.4)，forward 朝外；
  - 四个轴口中心：(±68.0,-1.2,0)、(0,-1.2,±68.0)；
  - 臂端：每象限 2 处，位置为 R_y(k·90°)·(4.0,-1.2,-68.0) 和 R_y(k·90°)·(68.0,-1.2,-4.0)。
- 正例：
  - 每个点都写出 local 值和由 N 推出的值，残差 ≤ 1e-6。
  - 礼堂接地点的 y 与围护接地点的 y 都是 -1.200（±2 mm）。
  - 4 个轴口宽 8.000，均以轴线居中；对应踏步宽 4.000，居中偏差 ≤5 mm。
  - 踏步外缘到围护内墙脚的净距为 47.250（±5 mm）。
  - 礼堂与围护之间 BVH 交叠为 0。
  - 端口 ID 和版本与 LY-072、LY-073 引用的完全相同（seams.json 中两条 seam：LY-071→LY-072、LY-071→LY-073）。
- 负例：

## T4 三档映射
- 映射表：近景 = 礼堂 LOD0 + L-LOD0×4；中景 = LOD1 + L-LOD1×4；远景 = LOD2 + L-LOD2×4。同一档内两件用同一档，不混用。
- 明确写一条：试配的「ENTRY_LOD0」实际是礼堂 LOD0 + 围护 LOD1。
- 正例：
  - 每一档都满足 T2 的变换和 T3 的端口。
  - 档间表面偏差不超过实测上限：礼堂 earth 为 0；围护 LOD0↔1 ≤15 mm，1↔2 ≤4 mm。

- 负例：

  - 用远景来证明近景通过，判失败。
