## T1 输入未漂移
- 正例：`sha256sum` 四个窑GLB = 上表。
- 负例：把任一窑GLB复制到临时目录改 1 字节 → 检查必须 FAIL。

## T2 互斥与共同加载（`support_check.py --exclude <V>_presentation_ground --add pit-<V>.glb`）
- 正例：kiln-A + pit-A、kiln-B + pit-B，原点与矩阵都是单位（不做缩放，不做二次平移）；回读节点数 = 窑 40（排除地坪后）+ 坑件。
- 负例 1：kiln-A + pit-B 必须 FAIL（以 T3 尺寸检查或 T5 侵入检查判定）。
- 负例 2：pit-A 与 pit-B 同时加载必须被装配规则拒绝（同一 `mutexGroup`）。
- 负例 3：保留 presentation_ground 再加坑件（旧新叠载）必须 FAIL：坑件与地坪的体积重叠 > 0。

## T4 底面支持（不靠展示底板虚托）
`support_check.py`，容差 0.02 m，每件 4×4 底面网格。
- 正例（排除地坪 + 坑件）：下列件**全部**样本有支持：`kiln_bed`（16/16）、`operation_pit_floor`（16/16）、`fire_floor`（16/16）、三个 `short_flue`（10/10）、4 级 `pit_access_step`、`chamber_walls`、`fire_hood`。
  基线（2026-11-05 实测）：无坑件时 15/40 件不完整支持；有展示地坪时坑底/火膛底仍为 0/16。
- 坑件自身：底面全部支持在坑件内部的基底上，或在契约写明的"宿主地坪切口底面"标高上；坑件不能有悬空底面。
- 允许并单独列出的点支持（不算失败，但要在报告写"点/边支持"）：`unfired_blank_C*` 搭在窑床瓦列上 4/16，`blank_drying_board_C` 由四腿承托。
- 晾坯台四腿（z=0，0/12）：若 LY-006 判给 LY-053，则坑件外圈必须托住；若判给 LY-054，报告写"本批移交 LY-054，未托"，不能计为通过。
- 负例：删除坑件中的窑床承台 → `kiln_bed` 必须回到 0/16，检查必须 FAIL。

## T5 操作口与排烟口不被封（保留盒 + 射线）
保留盒（坑件任何三角形不得进入；用 BVH 三角形—盒相交 + 盒内采样点 inside 测试两种方法）：
- 火门前保留盒：x∈[−0.9, 0.9]，y∈[−2.1 − d, −2.1]，z∈[−0.8, 0.95]，d = A 1.69 / B 1.09（到最低踏步立面的现有净深）。
- 坑内净空：坑平面 × z∈[−0.8, 0]，扣除源踏步体积。
- 烟道井：每个烟道内净口 × z∈[0, 1.22]；烟道上方 z∈[1.22, 3.0] 也不得有坑件或地形。
- 火膛槽：x∈[−0.9, 0.9]，y∈[−2.1, −0.4]，z∈[−0.8, 0]。
射线复核（`probe_openings.py`）：
- 火门地面以下净宽 ≥ 1.30 m（x±0.65，z −0.79…−0.49 每 5 cm 一层全通）。
- 烟道中心向下射线命中的第一个面必须是坑件的烟道底座顶面 z=0.000（不再穿出，也不在 z>0 被挡）。
- 坑中心 ±X、−Y 水平射线在 z −0.6/−0.3/−0.05 处必须命中坑件坑壁（基线：排除地坪后 ±X 3/3 未命中）。
- 负例：在火门前 0.3 m 处插一块 0.1 m 厚墙（临时文件）→ 必须 FAIL；把烟道底座顶面抬到 0.3 m → 必须 FAIL。

## T6 体积侵入与接触分类
- 坑件 × 窑件逐对：区分"合法共面接面"（坑壁内面与坑底板侧边、承台顶面与窑床底面 −0.6、底座顶面与烟道底面 0）、"正体积侵入"（> 0.002 m 深）和"完全包含"。
- 只做表面BVH时报告写"表面相交统计，未穷尽实体碰撞"。
- 窑体内部继承相交（`kiln_bed`×`fire_hood` 54 对、`chamber_walls`×`fire_hood` 约160 对，基线值）单列为"继承，未修"，数量不得因本包变化。
- 共面接面 z-fighting：承台顶面与窑床底面同为 −0.600 时，承台在窑床投影内不出顶面（或顶面下沉 ≤0.001 m 并说明），避免双面闪烁。

## T7 原子切地形契约
- 契约 JSON 必须有：`atomic: true`、窑本地切口多边形（坑口 + 火膛槽 + 窑床/烟道区，逐顶点）、各区切深（坑 1.04、窑床 0.6、烟道 0 封底）、宿主地坪片 ID（准入前为 `null` 并标"未指定"）、`replace` 与 `keep` 列表、`excludeNodes: ["<V>_presentation_ground"]`、撤回步骤。
- 正例：在一块临时平面地坪（复制，100×100 m，顶面 z=0）上按契约做一次"整块替换"，回读：切口内没有地面三角形高于 −0.001 m；切口外原地面顶点逐个不变（位置差 0）。
- 撤回：删除坑件与替换片、恢复原地坪片后，地坪 SHA 回到原值；窑节点矩阵/几何不变。
- 负例：只叠一块坑件、不切宿主地坪 → 坑口内检出地面三角形，必须 FAIL。
- 不在任何真实城市坐标上做这一步，直到 LY-010 给出准入。

## T8 两档对应
