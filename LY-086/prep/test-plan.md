## T2 墙洞关系（正例）
设墙块厚度为 T，墙洞净口为 W×H，墙洞位于沿 X 的区间 [a,b]。
- 墙洞净口要罩住段壳外皮：W ≥ 1.000 m（z±0.500），H ≥ 底板底 -0.180 到盖板顶 0.760 的 0.940 m。洞壁和段壳外皮的间隙 g 落在 0 ≤ g ≤ 0.010 m（端口契约另有规定时，以契约为准）。
- 水道在墙内这一段，沿 X 每 0.25 m 做一组横向射线：每根射线先命中墙洞壁，再命中段壳外皮。如果直接打进渠内净空，就判洞不封闭，记失败。
- 贯通：y∈{0.05,0.20,0.40}、z=0 沿 X 的射线，在 [-3.3,3.3] 内仍然 0 命中。也就是墙块不能把渠道堵住。
- 如果 T > 6.600 m（现有城垣 A/B 13.6 m、C 7.67 m 都是这种情况），就必须在 assembly.json 里明确写出解法：缩短墙块，或者标注「水道短于墙厚，端口落在墙内」。**不能拉伸水道**（禁止为接缝悄悄缩放）。

## T3 负例（必须失败）
- N1：墙块不开洞，直接叠放 → 段壳和墙体实体重叠体积 > 0，检查器判失败。
- N2：墙洞宽 0.90 m（比段壳外宽 1.00 m 窄）→ 侧向穿插，判失败。
- N3：把水道拉长到墙厚 → T1 判失败。
- N4：写出世界坐标（world != null）但 LY-003/010 没有放行 → 判失败。
- N5：装配里加了 flow/引水/排水/运营语义字段 → 判失败。

## T4 盖板与竖井
- 盖板（cover_C）底面 y=0.600 和侧墙顶面重合，偏差 ≤1e-4 m，归为合法共面接触。
- 盖板端头在 x=±0.750 侵入竖井砖面凸起 0.009 m（基线：每侧体积上限 1.44e-3 m³；BVH 三角对 128/133）。必须二选一并写进 qa：(a) 归类为合法局部接面并公开说明；(b) 盖板缩回 0.009 m 后重测，重叠为 0。**不能**把整个盖板和竖井这一对物件整体豁免。
- 竖井口 0.900×0.900 m，顶面 y=1.800。如果补井口盖，要标 C 并作为独立节点，可以撤回。井口和墙顶、地面的关系按 LY-005 地面端口测量，并给出高差数字。
- 墙块覆盖盖板的范围内，盖板顶 0.760 和墙洞顶之间的间隙另列一项。
