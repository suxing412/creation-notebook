## T2 槽前 / 入口 / 清扫路线的支持（本项验收①）
- T2.1 足下支持栅格：0.05 m 射线从 z=3.0 下射（排除屋面/瓦/檩），声明的槽前带、入口过渡、清扫路线每个格点都命中差异件或平台顶面，不得命中空（NONE）；支持面高差相邻格 ≤0.02 m，除声明台阶处。
- T2.2 槽前带：纵深从槽前面 y（A 1.075 / B 1.375）向外 ≥ 声明值（C 建议 ≥1.2 m），宽覆盖全部槽长 x 范围；与 LY-051 足迹布尔交集体积 ≤1e-6 m³（合法局部接面另列清单）。
- T2.3 入口：若 LY-005 给出城市地面 = 平台底（-0.24），则前沿须有坡道或台阶差异件，坡道坡度 ≤ 声明值（C 建议 ≤12.5%），单步 ≤0.18 m；若城市地面 = 平台顶，则阶差 |Δz| ≤0.01 m。均输出实际值。
- T2.4 清扫路线：声明一条连续折线，从槽前带→集水点→外接端口，沿线 0.6 m 宽（C，人+工具包络）通过栅格，无柱、无槽体侵入；路线不要求进入槽后 0.215 m 缝（如需清扫槽后，须注明不可达而非假装可达）。
- 负例 N2：删除坡道差异件，T2.3 必须失败（阶差 0.24 m）。
- 负例 N3：把清扫路线穿过一根前柱，T2.4 必须失败。

## T3 坡端与排水（本项验收①②）
- T3.1 找坡：差异件顶面每个面片的坡向朝向声明的集水点/沟，坡度在声明范围内（C 建议 0.5%–2%）；不存在反坡或局部洼点（栅格高程最小值只允许出现在集水点）。
- T3.2 沟/集水：沟底连续下降至终端；终端必须是以下之一：(a) 封闭集水坑几何（有底，体积 >0，标注容量）；(b) 外接端口盖板并在 assembly.json 标「出口未定，不接城市网」。
- T3.3 污水不消失：从任一沟段沿最陡下降追踪，必须到达 T3.2 的终端；到达模型外边界但无端口者 = 失败。
- T3.4 不假接古渠：差异件、端口和 assembly.json 中不出现任何城市渠/排水网节点 ID 或坐标；与城市水系层的交集为空。
- T3.5 滴水线：前/后檐滴水线（基准：平台边内 0.05 m）落在差异件的散水/沟范围内，或明确记录「滴水落在平台边、未处理」。
- 负例 N4：把沟终端改成开口落到模型外，T3.3 必须失败。
