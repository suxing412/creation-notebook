# LY-015 test plan（制作时直接跑）

## 公共约定

- 坐标用门体本地坐标，Blender Z 向上。
- 世界变换以 placement 为准：`T = Translation(2010.3973388671875, -21.3011474609375, 0.17) @ RotZ(-0.020743634087871412)`，除非 LY-005 冻结了新的契约。
- glTF 与 Blender 的换算：Blender (x, y, z) = glTF (x, −z, y)。
- 命令：`blender -b --factory-startup --python-exit-code 1 -P <script> -- ...`；纯 Python 用 `python -I`。
- 源包只解压到 scratch，并核对 ZIP SHA `bad99bb9f5b301b5b6a3450931511caec385df3da8b5ffc5b94b1664eb598c23`。
- 每份 QA 报告都要写明：受检文件的 SHA、检查脚本的 SHA、容差和负例结果。只报 PASS、不带负例的报告不算数。
- 容差默认值：
  - 位置：1e-3 m（接触用 2e-4 m）
  - 体积：1e-3 m³
  - 净空：0.01 m

## T0 输入未漂移

- 正例：`python -I make_inputs.py <pkg> inputs.json --verify` 返回 0，输出 INPUTS_OK。
- 负例：在 inputs.json 副本里把任一 SHA 改成全 0，必须返回 1 并输出 `DRIFT [...]`。2026-11-05 已实跑，返回 rc=1。
- 再加两项：LY-011 至 014 的交付 manifest SHA，以及 G 冻结包的 SHA。

## T1 三档读取与来源几何保留（本项验收①②）

- 对整组每个 GLB（LOD0/1/2 各一份装配包，加上原件引用）做导出回读：
  - glTF2，无扩展依赖，单个 GLB 不超过 15,000,000 字节；
  - 坐标值有限，UV0 齐全，纹理内嵌（LOD2 为 FLAT 无图，允许）；
  - 0 个退化三角，材质名属于 LY_P01 语义。
- 原件字节不变：
  - K-v1 三档：88d9a322…、d82f13fc…、13ff78a7…
  - 测试带：5754432a…、50f85502…、e758e45f…
  - 城墙：4e000b0c…、50d8c7aa…
  - 装配前后都必须吻合。
- 保留部分逐三角一致：派生件里没被遮罩的三角，其顶点、UV 与原件对应三角范围逐值相等（容差 1e-6）。三角范围取自 `qa/source-object-ranges.json`，用 verify_glb_ranges.py 的读法；该文件已证明范围在三档公开 GLB 中有效（ranges-out.json，all_match=true）。
- 负例：
  - 改动保留区一个顶点 1 mm，应失败；
  - 把 LOD0 复制改名成 LOD1，应失败（三角数、SHA 与原 LOD1 不符）；
  - 用远档代替近档报近景，应失败。

## T2 旧新互斥（本项验收③）

- 对每个被 011/012/013/014 替换的旧部件（至少包括 C_upper_deck、C_door_head_0..2、C_jamb_*、C_open_leaf_*、C_leaf_batten_*，以前置席位的冻结替换清单为准），在同一档装配里：
  - 旧件三角范围被遮罩 → 新件出现；
  - 未遮罩 → 新件不出现。
- 同时出现即失败。重叠判据：新旧件交体体积大于 1e-3 m³，或同一 y-z 截面内出现两层楼板。
- 用实体检测，不能只靠表面 BVH。在包围盒交集里按 0.05 m 网格做射线奇偶内点测试，必须能发现完全包含。
- 负例：
  - 故意叠加旧楼板和新楼板，必须检出约 84.32 m³（24.8×10×0.34）级别的重叠；
  - 若新楼板是 6.4 m 宽的条，应检出 21.76 m³。这一项待 bearing-section-v1 实物核对，现在只是算术推断。
  - 只保留表面 BVH 时，必须报告"不能声称实体穿插已穷尽"。

## T3 接墙件三档（城墙→整门替换清单）

- 正例：三档都有 terminal −1/+1 两件，作为独立节点，命名不与 `kaiyang-K-static_*` 冲突。
  - 内侧面 x=±12.4，y 在 [−5,5]，z 在 [0,5.0]，与门墩外侧面重合，残差不超过 2e-4。
  - 外侧四个角点与 wall-05、wall-04 当前 GLB 端面的四个角点残差不超过 2e-4（基线 placement 记为 1.22e-4）。
  - 外侧在本地坐标 x=±16.0，z 在 [0,6.03]，底宽 8.0、顶宽 5.6。
  - 体积合计 331.57 m³ ± 0.5（以 LOD1 试放实测为基线；若 LY-014 改变墙顶过渡，按其冻结端口重算）。
- 负例：
  - 去掉一侧接墙件，门墩与墙端之间必须测出 3.6 m 空缺；
  - 平移 0.01 m，残差检查必须失败。

## T4 实际门道路线（本项验收④ 前半）

- 身体包络默认 0.6×0.45×1.8 m（LY-010 若另定以其为准），货物或车辆按 LY-010 的规定。
- 连续扫掠：沿每条门道中线从 y=−7 到 +7，步长不超过 0.05 m，检查包络与门体、门叶、门框、门头、承托件的交体为 0。
- 每一步脚下都要有支承：下射命中地坪顶，阶差不超过 0.02 m。三条门道全宽都要检，不只检测试带。
- 基线（K-v1 原状）：
  - 净高 4.70；净宽 3.38 / 4.98 / 3.38（门叶处）；
  - 测试带支承比例 45.0% / 32.14% / 45.0%。门道两侧不支承的条形区若被计为通过，算失败。
- 负例：
  - 门关状态（若 LY-012 提供关闭态）必须阻断；
  - 抬高包络到 4.75 m 必须失败；
  - 去掉中间测试带，中门道支承必须失败。

## T5 上层路线（本项验收④ 后半）

- 从门外地面出发，经 LY-014 的登临件到楼板（5.34），再到两侧墙顶（6.03）：
  - 每一段都要有支承，踢面高度不超过 LY-010 或 014 冻结的上限；
  - 每一段都要满足包络净空：头顶到屋盖、系梁、椽不小于 1.8 m；
  - 端点对齐不超过 2e-3 m；
  - 要有 LY-014 规定的转身空间。
- 基线负例：K-v1 原状必须失败。地面到楼面没有路径（z 0.3 至 5.2 之间没有踏面）；楼板端下跌 0.34 m；墙顶比楼板高 0.69 m。
- 临空：以楼板顶以上 0.9 m 横射为参考，记录前沿、后沿、两端的被挡比例（基线 0/49、0/49、0/25、0/25）。只记录，不声称满足现代规范。
