## A. 平城包（`pingcheng_south_link_C`）

### A1 几何读取（正例）
- 导出后再用 Blender 读回，网格有限、没有退化三角（面积 > 1e-8）、有 UV 和法线、材质语义为路面土。单文件 < 15,000,000 B。
- 足迹：本地 y 的最小值 = -60.454 ± 0.002，最大值 = -6.353 ± 0.002（或 LY-006 冻结的边界值）；在每个 y 处，x 边界与母版分块同一 y 处的路边差 ≤ 0.002 m。
- 顶面本地 z = 0.040 ± 0.001，底面 = -0.010 ± 0.001，与 docs 路一致。

### A2 接缝（正例与容差）
- 在路端 y=-60.454 处与 docs `C_stitch_primary` 相接：接缝宽 ≤ 0.002 m，高差 ≤ 0.001 m，平面重叠 ≤ 0.01 m²（不许叠面）。
- 与 pingcheng-ground（每档 LOD 都查）：在 y∈[-10, -6.353] 段贴边，重叠 ≤ 0.01 m²，高差 ≤ 0.003 m（现在实测 0.002）。

### A3 侵入（负例：必须为零，或者被分类）
- 与门体 LOD0/1/2：三角相交 0 对，没有顶点在门体内，最近距离 ≥ 0 m（交付件 y_max ≤ -6.353）。
- 与 wall-04/05/06：0 相交。
- 按体积分类：合法局部接面只能是 A2 列出的两条接缝；不得有正体积侵入，也不得被完全包含。只做了表面 BVH 时，报告里写「表面相交检查」，不写成实体碰撞已穷尽。

### A4 连续支持（本项验收核心）
沿用 `route_whatif.py` 的逻辑，组合改用交付件替代查询窗口：
- P1 西：起点 (-7.9, -5.0) → 到达 y ≤ -65.0（落在 docs 路上）。LOD0/1/2 × 半宽 {0.3, 0.5, 以及 LY-005 冻结值} 全部为 true。
- P2 东：起点 (7.9, -5.0)，要求同上。
- N0 关掉交付件：两侧都止于 y ≥ -10（现实测为 -9.7 / -9.5）。
- N1 只留交付件、去掉门外地面：起点不可站。
- N2 去掉 docs 南路：止于 y ≥ -60.6（现实测为 -60.3）。
- N3 中门：起点 (0, -5.0)，必须被关闭的中门叶挡住（与 LY-017 的 N1 一致），不能借交付件「穿门」。
