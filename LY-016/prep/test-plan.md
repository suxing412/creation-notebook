## 2. 新增件检查（有新增件时跑；“复用”结论下只跑 T1、T2、T8）

把新增件 GLB（门局部坐标，三档）作为额外参数传给 route_check.py；它会进入 `delta` 层。

T3 不侵入固定门叶、门框、门墩（同档配对：delta-LODn vs gate-LODn）
- BVH 三角相交对：与 timber 0；与 earth 只允许出现在门墩竖直面 x = ±3.0/±5.8/±10.0 上的共面贴面，逐对列出并证明共面（法向夹角 < 0.1°、面距 < 1e-4 m）。
- 体积侵入：delta 顶点和顶面 0.05 m 栅格样点在 gate 任一件内的数量 = 0（三方向射线、2/3 多数票）。
- 门叶净空：开启门叶脚印 x∈±[9.69,9.83]、±[5.97,6.11]，y∈[-4.55,-2.69] 内 delta 顶面 ≤ 0.04（门叶底 0.05，余量 ≥ 0.01 m）；门框脚印 x∈±[9.8,10.0]、±[5.8,6.0]，y∈[-4.96,-4.64] 内 delta 不得有面。
- 负例：把一块 0.3×0.3×0.1 m 测试盒放进门框脚印（顶 0.06），检查必须报侵入；放在门叶下顶 0.06，必须报净空不足。

T4 不侵入旧路顶面、不叠层
- delta 与 C_stitch_primary 平面重叠面积 = 0（0.05 m 栅格）；接缝处 delta 顶与旧路顶高差 ≤ 0.005 m；三角相交只允许接缝共面贴边。
- delta 与原地面附件平面重叠 = 0（不重复包地）。
- 负例：把 delta 平移 0.2 m 到旧路上，检查必须报重叠。

T5 支持域扩展（只在采用 B/C 方案时）
- 用 G 冻结的包络重跑 route_check：两环无支承 = 0，最大中心台阶 ≤ G 规定值（未规定时用 0.02 m）。
- 宽包络正例：脚带半宽改为冻结值（如 0.9 m），记录 现状（无 delta）的失败点数与 有 delta 的失败点数；后者必须为 0，前者 > 0 才说明这块新增件有用。
- 关闭旧路负例 N1 仍须失败（delta 不得变成绕开旧路的替代路）。
- 中门负例 N2 仍须失败（delta 不得伸进中央门道 x∈[-3,3] 的门叶线）。

T6 暴露边
- 统计地面＋delta 周长中：贴旧路、贴门墩、暴露。报告暴露边长度与落差，与基线 40.0 m（门道内）/ 67.2 m（门外）、落差 0.20 m 对比。

T7 三档一致与质量底线
- delta 三档占地错格 0；三档不是同一几何改名（三角数或细节不同，且 LOD0 不复制给其他档）。
- 单 GLB ≤ 15,000,000 字节；有 UV0、法线；无退化三角；坐标有限；米制；原点即门局部原点；材质语义沿用 LY_P01_earth 角色（以 LY-007 冻结为准）。
