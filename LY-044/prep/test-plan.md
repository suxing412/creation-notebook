# LY-044 测试计划（制作时直接运行）

本计划对应任务池「本项验收」的三条：

1. 灶、备食台、人行/转身域分别检测；
2. 主体、台案与地坪可以整体回退；
3. 不输出燃烧或防火合格结论。

## 约定

- **坐标**：glTF 坐标系。x 向东，y 向上，z 等于负的本地北，单位米。
- **工具**：所有几何检查用 Blender 5.2.1，命令为 `-b --factory-startup --python-exit-code 1`。
- **基础脚本**：`prep/measure_ly044.py`、`prep/probe_place.py`。制作时把它们改成读 `assembly.json` 的版本。
- **报告**：每份报告都写入实际输入的 SHA256，并注明范围：表面射线和顶点检查，不是实体碰撞穷尽，不是 GPU 或浏览器实测，不是步态模拟。
